# 设计图提示词

## 画风

1. **画面类型**：角色设计图，全身三视图（正面、侧面、背面），单张图片三个视角并排展示，三视角保持外观一致
2. **背景**：#00FF00 纯绿色背景（chroma key green）
3. **线条**：细线稿，外轮廓线略粗，内部结构线较细，面部线条极细；线条圆润柔和，光滑干净，纯黑色，线条变化中等
4. **上色与光影**：半厚涂上色，Anime Illustration 主体渲染；软阴影，柔和渐变；单主光源，环境光弱，高光强度中等偏弱，明暗对比低
5. **比例**：7.5 头身，半写实动画比例
6. **色调**：暖色调，色温偏暖，中低饱和度，色彩对比低；整体呈现慵懒、讨好、怯懦宅男的屏幕倦怠气质

## 角色设定

1. **体型**：身高约 175cm，瘦削单薄的少年感体态，常年久坐缺乏运动而略显孱弱；肩膀略前倾含胸，四肢纤细；静态站姿松垮，重心略向前坠，气质疏懒倦怠，神情带着讨好又畏缩的怯意
2. **面部**：中国面孔，青年感；脸型偏圆，符合圆形形状语言；黑色圆眼，瞳色偏深，常因熬夜而眼眶泛红，目光游移不定、躲闪却又黏人；薄唇，唇色偏淡；眼下有明显青黑黑眼圈，神情倦怠讨好、怯懦畏缩
3. **发型**：黑色微乱短发，刘海略长遮住额前，缺乏打理，发尾有些毛躁；整体质感蓬乱缺乏光泽，呈现久坐屏幕前疏于打理的宅男发感
4. **贴身基础衣物**：穿着深色基础衣物（黑色贴身背心+深色短裤），与苍白肤色形成高对比，仅作底装，不涉及服装设计细节
5. **外貌配色**：发色纯黑，瞳色深黑偏深，肤色苍白泛青；整体外貌配色在中低饱和暖色调下，以黑发苍白肤色形成柔和对比，眼下青黑黑眼圈点缀出常年熬夜的倦态
6. **特殊标记**：双眼下明显的青黑色黑眼圈，是常年熬夜屏幕前的标志特征

## 风格参考

Japanese Commercial Illustration，Semi-realistic Anime，日系商业角色插画风格，动画风 70% + 写实风 30%，轻小说封面风倾向；角色设计图用途，全身三视图静态站姿，双手自然垂于身侧，无动态手部动作。
