# 设计图提示词

## 画风

1. **画面类型**：角色设计图，单张图片并排展示正面、侧面、背面三个视角的全身三视图，三个视角外观与气质保持一致；韩系平涂角色插画（Korean Flat-shading Illustration）风格，参考韩国商业插画与韩系手游角色美术的清爽精致质感，写实度 6/10（写实风 40% + 动画风 60%），以干净色块、清爽配色与精致细节呈现现代商业插画的平面美感。
2. **背景**：纯绿色背景（chroma key green，#00FF00）。
3. **线条**：干净的细到中等线稿，线条为深色（深棕 / 近黑）、粗细有变化（外轮廓略粗、细节纤细），线条干净利落但略柔和，呈现代商业插画的精致勾线感。
4. **上色与光影**：平涂（flat-shading）上色为主，色块干净平整；阴影为清晰的分层平涂阴影，但阴影边缘比硬边赛璐璐略柔（半硬边 / 带轻微渐变过渡），层次分明；皮肤有轻微渐变过渡（非纯平面），整体清爽精致；单一主光源，高光简洁点缀。
5. **比例**：7.5 头身的修长比例，肩颈纤长、四肢舒展、腰线清晰，保留精致的美化与时尚感。
6. **色调**：冷调（黑发、苍白泛青肤色为主，青黑黑眼圈点缀），清爽高级的配色，饱和度中低，色彩干净和谐，整体通透。

## 角色设定

1. **体型**：身高约 175cm，瘦削单薄的少年感体态，常年久坐缺乏运动而略显孱弱；肩膀略前倾含胸，四肢纤细；静态站姿松垮，重心略向前坠，气质疏懒倦怠，神情带着讨好又畏缩的怯意
2. **面部**：中国面孔，青年感；脸型偏圆，符合圆形形状语言；黑色圆眼，瞳色偏深，常因熬夜而眼眶泛红，目光游移不定、躲闪却又黏人；薄唇，唇色偏淡；眼下有明显青黑黑眼圈，神情倦怠讨好、怯懦畏缩
3. **发型**：黑色微乱短发，刘海略长遮住额前，缺乏打理，发尾有些毛躁；整体质感蓬乱缺乏光泽，呈现久坐屏幕前疏于打理的宅男发感
4. **贴身基础衣物**：穿着深色基础衣物（黑色贴身背心+深色短裤），与苍白肤色形成高对比，仅作底装，不涉及服装设计细节
5. **外貌配色**：发色纯黑，瞳色深黑偏深，肤色苍白泛青；整体外貌配色在中低饱和暖色调下，以黑发苍白肤色形成柔和对比，眼下青黑黑眼圈点缀出常年熬夜的倦态
6. **特殊标记**：双眼下明显的青黑色黑眼圈，是常年熬夜屏幕前的标志特征

## 风格参考

Korean Flat-shading Illustration，韩系商业角色插画风格，动画风 60% + 写实风 40%，清爽精致的现代商业插画；角色设计图用途，全身三视图静态站姿，双手自然垂于身侧，无动态手部动作。
