# 设计图提示词

## 画风
<!-- 数据来源：00_init/美术风格.md -->

1. **画面类型**：角色设计图，全身三视图（正面、侧面、背面），日系商业角色插画风格，半写实动画风，轻小说封面风
2. **背景**：纯绿色背景（#00FF00，chroma key green）
3. **线条**：细线稿，外轮廓线略粗，内部结构线较细，面部线条极细，线条变化中等，圆润柔和的光滑干净黑色线条
4. **上色与光影**：半厚涂，Anime Illustration 主体渲染，软阴影，柔和渐变的阴影边缘，低明暗对比，单主光源，弱环境光，中等偏弱的高光强度
5. **比例**：7.5头身，少女体型比例
6. **色调**：暖色调，偏暖色温，中低饱和度，低色彩对比

## 角色设定

1. **体型**：身高约163cm，娇小匀称的少女体型，圆形形状语言主导轮廓，圆润柔和的肩线，四肢纤细，腰线清晰，整体散发被宠溺长大的精致感与少女的稚气活力，静态站姿自然直立
2. **面部**：圆润鹅蛋脸，深棕色下垂圆眼，眼型圆润下垂呈现天真无辜感，眉型柔和，鼻型小巧精致，饱满的唇形呈现嘟唇感，瓷白肤色，默认表情带着软糯甜腻的黏人气质，眼神黏人带着天真
3. **发型**：栗棕色柔顺长直发，发长及腰，发质光泽顺滑自然披散，碎发自然垂落修饰脸型
4. **贴身基础衣物**：穿着深色基础衣物（黑色贴身背心+深色短裤），与瓷白肤色形成高对比，不涉及服装设计细节
5. **外貌配色**：主色调为奶白色与樱花粉的贵气甜美组合，辅以薰衣草紫的娇贵少女感，点缀蜜桃金的富家千金精致感。发色为栗棕色，瞳色为深棕色，肤色瓷白，整体高明度低饱和，营造软糯无害的甜系氛围，紫色点缀暗示其任性与被宠溺的底色
6. **特殊标记**：无明显疤痕、纹身或胎记
