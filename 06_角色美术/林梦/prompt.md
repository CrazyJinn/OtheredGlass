# 设计图提示词

## 画风
<!-- 数据来源：00_init/美术风格.md -->

1. **画面类型**：角色设计图，全身三视图（正面、侧面、背面），日系商业角色插画风格，半写实动画风，轻小说封面风
2. **背景**：纯绿色背景（#00FF00，chroma key green）
3. **线条**：细线稿，外轮廓线略粗，内部结构线较细，面部线条极细，线条变化中等，圆润柔和的光滑干净黑色线条
4. **上色与光影**：半厚涂，Anime Illustration 主体渲染，软阴影，柔和渐变的阴影边缘，低明暗对比，单主光源，弱环境光，中等偏弱的高光强度
5. **比例**：7.5头身，少女体型比例
6. **色调**：暖色调，偏暖色温，中低饱和度，低色彩对比

## 角色设定
<!-- 数据来源：AppearanceStyle 节点（appearance + tags）+ Character 节点（color_direction） -->

1. **体型**：身高约168cm，骨架偏大的少女体型，圆形形状语言主导整体轮廓，体态匀称，肩线圆润柔和，四肢纤实，腰线清晰，呈现大号萝莉般的精致活力感，静态站姿自然直立，双手自然垂于身侧
2. **面部**：中国面孔，圆润鹅蛋脸型，大而明亮的眼眸，眼神黏人带着天真，眉型柔和自然，鼻型小巧精致，唇形饱满，瓷白肤色，默认表情呈现软糯甜腻、甜美开朗的千金大小姐气质
3. **发型**：银色短发，发质光泽顺滑，发丝自然披散修饰脸型，碎发轻盈垂落
4. **基础衣物**：穿着深色简约基础衣物（深色长袖训练服与深色长裤），与瓷白肤色形成适度对比，不涉及服装设计细节
5. **外貌配色**：主色调为奶白色与樱花粉的贵气甜美组合，辅以薰衣草紫的娇贵少女感，点缀蜜桃金的富家千金精致感。发色为银色，肤色瓷白，整体高明度低饱和，营造软糯无害的甜系氛围，紫色点缀暗示其任性与被宠溺的底色
6. **特殊标记**：无明显疤痕、纹身或胎记
