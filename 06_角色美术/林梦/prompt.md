# 设计图提示词

## 画风

1. **画面类型**：角色设计图，全身三视图（正面、侧面、背面），静态站姿，双手自然垂于身侧
2. **背景**：#00FF00 纯绿色背景（chroma key green）
3. **线条**：细线稿，外轮廓略粗，内部结构线较细，面部线条极细，圆润柔和的光滑干净线条，纯黑色
4. **上色与光影**：半厚涂，Anime Illustration 主体渲染，软阴影柔和渐变，单主光源、环境光弱、高光中等偏弱
5. **比例**：7.5 头身，少女体型
6. **色调**：暖色调偏暖，中低饱和，低对比；整体高对比、明度跨度大，黑色主导

## 角色设定

1. **体型**：约 168cm，身材高挑的少女，身形紧实且轮廓圆润，整体呈现叛逆少年风格，三角型形状语言，站姿挺拔，神态桀骜
2. **面部**：中国面孔，圆脸，饱满唇形常微微撇着不屑的劲儿；琥珀色上挑眼型，眼尾天生带钩，看人习惯性半眯斜睨，眉形上挑，瓷白肤色；默认表情是桀骜不屑的神态，带锐利的少年感
3. **发型**：银色短碎发，发尾凌乱外翘，不对称薄刘海遮住半边眉，质感轻盈带凌乱挑染感
4. **基础衣物**：穿着深色基础衣物（黑色打底背心+深色短裤），与瓷白肤色形成高对比，仅作为基础衣物，不涉及服装设计细节
5. **外貌配色**：主色哑光黑与深炭灰（叛逆基底）用于基础衣物，辅色电光粉与亮紫（亚文化风格·锐利感）点亮发丝挑染与眼部神采，点缀色金属银（铆钉/链条/耳钉·硬核质感）呼应银发；整体黑色主导，暗示其桀骜不羁的锋芒
6. **特殊标记**：无疤痕、纹身、胎记等特殊标记
