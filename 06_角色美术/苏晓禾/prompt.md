# 设计图提示词

## 画风

1. **画面类型**：角色设计图，单张图片并排展示正面、侧面、背面三个视角的全身三视图，三个视角外观与气质保持一致；韩系平涂角色插画（Korean Flat-shading Illustration）风格，参考韩国商业插画与韩系手游角色美术的清爽精致质感，写实度 6/10（写实风 40% + 动画风 60%），以干净色块、清爽配色与精致细节呈现现代商业插画的平面美感。
2. **背景**：纯绿色背景（chroma key green，#00FF00）。
3. **线条**：干净的细到中等线稿，线条为深色（深棕 / 近黑）、粗细有变化（外轮廓略粗、细节纤细），线条干净利落但略柔和，呈现代商业插画的精致勾线感。
4. **上色与光影**：平涂（flat-shading）上色为主，色块干净平整；阴影为清晰的分层平涂阴影，但阴影边缘比硬边赛璐璐略柔（半硬边 / 带轻微渐变过渡），层次分明；皮肤有轻微渐变过渡（非纯平面），整体清爽精致；单一主光源，高光简洁点缀。
5. **比例**：7.5 头身的修长比例，肩颈纤长、四肢舒展、腰线清晰，保留精致的美化与时尚感。
6. **色调**：暖调（阳光橙、薄荷绿与暖白为主），清爽高级的配色，饱和度中等，色彩干净和谐、有现代商业插画的设计感，整体明亮通透。

## 角色设定

1. **体型**：身高约166cm，匀称健美的运动型身材，长期锻炼带来的轻盈体态，肩颈线条利落，四肢修长且带有不过分突出的肌肉线条；以圆形为造型语言，整体呈现成熟而阳光清爽的运动少女气质，像清晨第一缕阳光般明朗洁净，给人健康有活力、笑起来令人心情变好的第一印象
2. **面部**：健康粉的肤色，琥珀色杏眼，弯弯的微笑唇，神情明朗亲和，默认带着温和自信的笑意
3. **发型**：中长发，深棕色打底并挑染色粉色，运动感利落，不拖沓
4. **贴身基础衣物**：仅穿着深色基础衣物（黑色贴身背心搭配深色短裤），与肤色形成高对比，不含任何服装设计细节
5. **外貌配色**：瞳色为琥珀色，肤色为健康粉色；整体配色以阳光橙(#FF8C42)为主色传递运动活力与温暖，辅以薄荷绿(#7FC8A9)呼应健康康复主题，并以暖白(#FFF8F0)与深棕(#3D2817)沉淀稳重感，整体偏亮调，体现开朗通透的性格
6. **特殊标记**：无明显疤痕、纹身或胎记
