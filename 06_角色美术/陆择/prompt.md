# 设计图提示词

## 画风

1. **画面类型**：角色设计图，单张图片并排展示正面、侧面、背面三个视角的全身三视图，三个视角外观与气质保持一致；韩系平涂角色插画（Korean Flat-shading Illustration）风格，参考韩国商业插画与韩系手游角色美术的清爽精致质感，写实度 6/10（写实风 40% + 动画风 60%），以干净色块、清爽配色与精致细节呈现现代商业插画的平面美感。
2. **背景**：纯绿色背景（chroma key green，#00FF00）。
3. **线条**：干净的细到中等线稿，线条为深色（深棕 / 近黑）、粗细有变化（外轮廓略粗、细节纤细），线条干净利落但略柔和，呈现代商业插画的精致勾线感。
4. **上色与光影**：平涂（flat-shading）上色为主，色块干净平整；阴影为清晰的分层平涂阴影，但阴影边缘比硬边赛璐璐略柔（半硬边 / 带轻微渐变过渡），层次分明；皮肤有轻微渐变过渡（非纯平面），整体清爽精致；单一主光源，高光简洁点缀。
5. **比例**：7.5 头身的修长比例，肩颈纤长、四肢舒展、腰线清晰，保留精致的美化与时尚感。
6. **色调**：浅暖调（奶白、燕麦卡其为主，暖金与琥珀点缀），清爽高级的配色，饱和度中等，色彩干净和谐、有现代商业插画的设计感，整体明亮亲和。

## 角色设定

1. **体型**：约185cm，身形匀称、打理得当的青年，肩线利落，下颌线条利落，静态站姿挺拔但不僵硬，双手自然垂于身侧；身材匀称有气色，整体给人干净、清爽、有亲和力的第一印象
2. **面部**：中国面孔，五官清秀偏柔，眉眼温和，嘴角习惯性微扬呈微笑唇，狭长的深棕色眼睛，眼尾微挑，瞳孔带暖金与琥珀色高光，眼底含笑意，看人时温和讨喜，眼底却藏着精明与算计的锋芒；默认表情是表面讨喜的浅笑，温暖亲和的皮囊下藏着玩世不恭的渣男内核
3. **发型**：柔顺的黑色短发，打理得当，刘海自然斜分，干净有造型感，整体清爽耐看，发质顺滑不毛躁
4. **贴身基础衣物**：穿着黑色贴身背心与深色短裤，与肤色形成高对比，仅作基础衣物呈现，不涉及服装设计细节
5. **外貌配色**：主色为奶白与燕麦卡其的浅暖调底色，辅色为健康匀净、带一点暖光的健康粉色肤色，气色好；点缀色为暖金与琥珀色，落于眼神高光与瞳孔深处——金色比银色更有热乎劲与逢迎感，一眼有亲和力又带点精明；黑色短发与浅暖肤色形成干净清爽的对比
6. **特殊标记**：无疤痕、无纹身、无胎记，皮肤干净匀净
