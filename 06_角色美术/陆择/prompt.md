# 设计图提示词

## 画风

1. **画面类型**：角色设计图，全身三视图（正面、侧面、背面），三个视角并排展示
2. **背景**：纯绿色背景（#00FF00，chroma key green）
3. **线条**：细线稿，外轮廓线略粗，内部结构线较细，面部线条极细，圆润柔和风格，光滑干净纹理，线条颜色为纯黑
4. **上色与光影**：半厚涂上色，Anime Illustration 主体渲染，软阴影，柔和渐变边缘，单主光源，弱环境光，高光强度中等偏弱
5. **比例**：7.5 头身，半写实日系商业插画风格，轻小说封面风，写实度 6.5/10
6. **色调**：以苍白肤色与黑色发色为主，点缀冷银色高光，大面积暗灰呼应颓废气质，沉闷躯壳与锐利灵魂的视觉张力，整体中低饱和度，低对比度

## 角色设定

1. **体型**：身高约 178cm，偏瘦，肩窄骨架轻，久坐宅男的瘦削体型，细长型轮廓，苍白肤色缺乏阳光，少年感的清瘦身形，肩线略窄，四肢纤细，静态站姿略带颓废感但眼神锐利
2. **面部**：清秀偏柔的面部线条，下颌略尖，原本是清秀宅男感的五官，但眼神带着不属于这具身体的玩世不恭与精明算计，形成躯壳与灵魂割裂的违和感。黑色狭长上挑眼，薄唇，神情是从颓废麻木到游刃有余的过渡态，带着一丝玩世不恭的冷笑意味
3. **发型**：黑色蓬乱中长发，缺乏打理，碎发散乱，整体呈颓废未打理的质感，发丝间透出宅男长期不修边幅的生活状态
4. **贴身基础衣物**：穿着黑色贴身背心与深色短裤，与苍白肤色形成高对比，仅作基础遮蔽，不涉及服装设计细节
5. **外貌配色**：主色为苍白的肤色与黑色的头发，辅以暗灰的整体氛围，点缀冷银色的眼神高光。苍白肤色强化宅男长期不见光的病态感，冷银点缀代表穿越者锋利算计的灵魂
6. **特殊标记**：无疤痕、纹身、胎记等特殊标记
