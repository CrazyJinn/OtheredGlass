# 设计图提示词

## 画风

1. **画面类型**：角色设计图，全身三视图（正面、侧面、背面），半写实日系商业插画，轻小说封面风，写实度6.5/10
2. **背景**：#00FF00 纯绿色背景（chroma key green），用于后期抠图
3. **线条**：细线稿，外轮廓线略粗，内部结构线较细，面部线条极细，圆润柔和，光滑干净，纯黑色
4. **上色与光影**：半厚涂，Anime Illustration 风格主体渲染，软阴影，柔和渐变，低明暗对比，单主光源，弱环境光，中等偏弱高光
5. **比例**：7.5头身，身形匀称的青年比例
6. **色调**：暖色调，偏暖色温，中低饱和度，低对比，整体干净亲和

## 角色设定

1. **体型**：约185cm，身形匀称、打理得当的青年，肩线利落，下颌线条利落，静态站姿挺拔但不僵硬，双手自然垂于身侧；身材匀称有气色，整体给人干净、清爽、有亲和力的第一印象
2. **面部**：中国面孔，五官清秀偏柔，眉眼温和，嘴角习惯性微扬呈微笑唇，狭长的深棕色眼睛，眼尾微挑，瞳孔带暖金与琥珀色高光，眼底含笑意，看人时温和讨喜，眼底却藏着精明与算计的锋芒；默认表情是表面讨喜的浅笑，温暖亲和的皮囊下藏着玩世不恭的渣男内核
3. **发型**：柔顺的黑色短发，打理得当，刘海自然斜分，干净有造型感，整体清爽耐看，发质顺滑不毛躁
4. **贴身基础衣物**：穿着黑色贴身背心与深色短裤，与肤色形成高对比，仅作基础衣物呈现，不涉及服装设计细节
5. **外貌配色**：主色为奶白与燕麦卡其的浅暖调底色，辅色为健康匀净、带一点暖光的健康粉色肤色，气色好；点缀色为暖金与琥珀色，落于眼神高光与瞳孔深处——金色比银色更有热乎劲与逢迎感，一眼有亲和力又带点精明；黑色短发与浅暖肤色形成干净清爽的对比
6. **特殊标记**：无疤痕、无纹身、无胎记，皮肤干净匀净
