# 设计图提示词

## 画风

1. **画面类型**：角色设计图，全身三视图（正面、侧面、背面三个视角并排展示），韩系商业角色插画风格（Korean Flat-shading Illustration / Korean Cel-shading），动画风 60% 加写实风 40%，写实度 6/10，清爽精致的现代商业插画质感。
2. **背景**：纯绿色背景（chroma key green，#00FF00），用于后期抠图。
3. **线条**：细到中等线稿，外轮廓线略粗，内部结构线较细，面部线条极细；线条干净利落略柔和，平滑干净带有从外轮廓到细节的粗细过渡；线条颜色为深棕色接近黑色。
4. **上色与光影**：平涂上色（Flat-shading），主体为干净色块，分层平涂阴影，阴影边缘为半硬边（比硬边赛璐璐略柔、带轻微渐变过渡）；中等明暗对比，单主光源，弱环境光，高光简洁点缀，皮肤呈轻微渐变过渡而非纯平面。
5. **比例**：7.5 头身，曼妙匀称的高挑身材比例。
6. **色调**：清爽高级的色调，中等饱和度，靠明暗与色块层次形成中等色彩对比；整体配色为大面积低饱和深色加高光区域明亮——皮肤与浅色区域形成画面高光，红唇与暗金点缀作为视觉焦点。

## 角色设定

1. **体型**：约 172cm 的高挑身材，曼妙匀称的曲线，肩线清晰，下颌线利落；静态站姿挺拔而从容，肩线微微打开，躯干含一丝慵懒的松弛感，气质慵懒妩媚却自带冷意；整体呈现不对称的形体语言，疏离眼神下藏着掌控全局的从容，是一个不怒自威的成熟女性，目光冷淡地审视观者。
2. **面部**：中国面孔，脸型精致微长，下颌线清晰利落；眉峰略挑；一双黑色上挑眼，眼尾微扬，天然带着审视的疏离感；薄唇紧抿显出几分凌厉；象牙白肌肤，明暗对比下皮肤区域为画面高光；默认表情冷淡克制，透出成熟御姐的威压与疏离。
3. **发型**：黑色微卷长发，垂至腰际，发丝自然微卷带有慵懒的弧度，深棕近黑的发色在光线下建立视觉锚点，自然披散时透着小资情调的随意。
4. **贴身基础衣物**：穿着深色基础衣物（黑色贴身背心搭配深色短裤），与象牙白肤色形成高对比，仅作设计图基底，不涉及服装设计细节。
5. **外貌配色**：主色为冷调象牙白肤色与深酒红（唇色，呼应经理的克制感与暗藏掌控欲）；辅色为深棕色（呼应发色，建立视觉锚点）；点缀色为暗金色（小资精致的配饰细节感）；红唇与暗金点缀作为画面视觉焦点，营造沉静而锋利的存在感。
6. **特殊标记**：眼角处有一颗泪痣，为冷感面容增添一抹精致的记忆点。

## 静态姿态说明

三视图均为静态站姿，双手自然垂于身侧或微微张开，禁止出现交叠、叉腰、持物等动态手部动作；体态气质差异通过肩线、重心与躯干的松弛/挺拔状态体现。
