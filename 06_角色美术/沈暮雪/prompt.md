# 设计图提示词

## 画风
<!-- 数据来源：00_init/美术风格.md -->

1. **画面类型**：角色设计图，全身三视图（正面、侧面、背面三个视角并排展示），日系商业角色插画风格，半写实动画风（动画风 70% + 写实风 30%），轻小说封面质感
2. **背景**：纯绿色背景（#00FF00），用于后期抠图
3. **线条**：细线稿，外轮廓线略粗，内部结构线与面部线条极细，圆润柔和，光滑干净，纯黑色，线条变化中等
4. **上色与光影**：半厚涂，主体为动画插画式渲染，软阴影，柔和渐变边缘，明暗对比偏低，单主光源，环境光弱，高光中等偏弱
5. **比例**：7.5 头身，细长型身材比例
6. **色调**：暖色调，色温偏暖，中低饱和度，色彩对比低，整体以低饱和深色为主、高光区域明亮

## 角色设定
<!-- 数据来源：AppearanceStyle 节点 + Character 节点 -->

1. **体型**：身高约 172cm，曼妙匀称的高挑身材，肩线清晰，腰线收紧，四肢修长；轮廓呈细长型，整体气质慵懒妩媚却自带冷意；静态站姿自然挺直，重心略偏后，透出掌控全局的从容感
2. **面部**：精致微长的脸型，下颌线清晰利落，眉峰略挑显出冷感；眼尾微微下垂带着疏离感，黑色上挑眼，瞳色为纯黑；薄唇，唇线清晰；左眼下方有一颗泪痣作为面部标志；默认表情是冷淡审视的神情，不怒自威
3. **发型**：黑色微卷长发，发长垂至腰际，自然披散时呈现小资情调的随意感，发丝柔软有光泽，发尾自然卷曲；碎发自然散落在脸侧与肩头
4. **贴身基础衣物**：穿着黑色贴身背心与深色短裤，与象牙白肤色形成高对比，仅作为基础底装，不涉及任何服装设计细节
5. **外貌配色**：发色为纯黑呼应整体配色，瞳色为纯黑，肤色为冷调象牙白；唇部点出深酒红色作为视觉焦点，泪痣强化面部精致感；外貌整体配色逻辑以大面积低饱和的纯黑发色为视觉锚点，象牙白肤色形成画面高光，深酒红唇色作为锐利点缀
6. **特殊标记**：左眼下方泪痣，是面部标志性细节

## 三视图规则

- 单张图片包含正面、侧面、背面三个视角并排展示，三视角外观与气质完全一致
- 全身像，每个视角完整展示角色全身设计
- 静态站姿，双手自然垂于身侧，禁止出现交叠、叉腰、持物等动态手部动作
- 体态气质通过肩线、重心、挺胸等躯干状态体现
- 不使用负面提示词，仅通过正面描述控制画面
