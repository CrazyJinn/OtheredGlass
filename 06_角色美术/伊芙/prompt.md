# 伊芙 · 角色设计图（三视图）

## 主体

1. 少女角色全身三视图设计稿（正面 / 侧面 / 背面），7.5 头身，身高约 165cm
2. 韩系商业角色插画风格的角色设定图，干净清爽精致

## 角色整体气质

约 165cm，柔和匀称的少女体态，肌肤透着微光。脸庞圆润温柔，眉眼弯弯带着梦呓般的朦胧感，常有发丝不经意垂落脸颊。金色长发如瀑布般垂至腰际，发梢自然卷曲如羽毛。

梦幻、温柔、略带朦胧的天使之姿；第一印象仿佛随时会飘走的柔软云朵，让人忍不住想守护。

## 维度细节

- 造型语言：圆形（整体轮廓与五官以圆形主导，呈现柔软柔和感）
- 年龄印象：少女
- 体态：匀称
- 肤色：瓷白（带微光透亮感）
- 发型发色：金色超长大波浪长发，如瀑布般垂至腰际，发梢自然卷曲如羽毛
- 眼型瞳色：淡紫色圆杏眼，瞳孔里似有星辰流动，常有失神的朦胧感
- 唇形：饱满
- 面部：雅典人面容，眉眼弯弯带梦呓般的朦胧感
- 特殊标记：无

## 配色逻辑

梦幻温柔天使配色：金色长发与淡紫色圆杏眼形成柔和互补色对映，瓷白肌肤泛微光，整体笼罩柔和朦胧的光晕。色调清爽高级，饱和度中等，光感通透。

## 贴身基础衣物（设计图统一基准）

深色基础衣物：黑色贴身背心 + 深色短裤，与瓷白肌肤形成高对比，便于观察身体比例与结构；不涉及具体服装款式。

## 画面背景

全身像位于纯绿色（chroma key green，#00FF00）背景前，便于后期抠图。

## 画风

- 风格定位：韩系平涂插画（Korean Flat-shading / Cel-shading Illustration），清爽精致的现代商业插画
- 写实度：6 / 10，动画风 60% + 写实风 40%
- 头身比：7.5 头身
- 分辨率：1024 × 1024
- 线稿：细到中等线稿，外轮廓略粗，内部结构线较细，面部线条极细；线条干净利落略柔和，平滑干净，颜色为深棕至近黑
- 上色：平涂为主，干净色块，分层平涂阴影，半硬边（带轻微渐变过渡）；明暗对比中等；单主光源，弱环境光，高光简洁点缀；皮肤轻微渐变过渡（非纯平面）
- 色彩：色调清爽高级，色温按角色中性偏暖，饱和度中等，色彩对比靠明暗与色块层次
