# 着装提示词

## 画风

- 风格：Korean Flat-shading Illustration / Korean Cel-shading，韩系商业角色插画
- 背景：#00FF00 纯绿色背景（chroma key green）
- 线条：细到中等线稿，外轮廓略粗、内部结构线较细、面部线条极细；干净利落略柔和，平滑干净；深棕色近黑的线条颜色
- 上色与光影：平涂（Flat-shading），干净色块，分层平涂阴影，阴影半硬边（略柔带轻微渐变过渡），中等明暗对比；单主光源、简单光照、弱环境光；高光简洁点缀；皮肤轻微渐变过渡
- 比例：7.5 头身；写实度 6/10，动画风 60% + 写实风 40%
- 色调：清爽高级，中性偏暖；中等饱和度；中等色彩对比
- 分辨率：1024 × 1024

## 着装描述

1. **开头声明**：伊芙立绘设计图，#00FF00 纯绿色背景，全身三视图（正面、侧面、背面）；以已批准的 DesignSheet 设计图为图生图参考底图，角色外貌（已在底图中）保持一致，本提示词仅描述着装
2. **整体风格**：可爱与古希腊风格相融合的少女天使灵魂引路人着装，垂坠自然、古朴轻盈，气质温柔梦幻
3. **着装款式**：主体为一件未漂白亚麻粗布长及脚踝的长裙，剪裁宽松、自肩线顺势垂坠，呈现古希腊 chiton 式的自然褶皱；腰间以一根原色亚麻绳系束收腰，绳结系扎后两端自然垂落，勾勒柔和腰线；上衣为同料亚麻粗布喇叭长袖，袖身贴合上臂、袖口向手背张开成喇叭状
4. **材质质感**：未漂白原色亚麻粗布，纤维粗粝质朴，保留亚麻本味的米白偏黄原色；表面可见亚麻织纹与轻微毛羽，呈现手工乡村质感的自然做旧外观；不做刺绣或缝线装饰
5. **配色**：通体以未漂白亚麻的米白原色为主色，腰绳同为原色亚麻色，整体为低饱和的浅米色调；无强对比的辅色，仅在配饰处点缀
6. **鞋袜**：赤足，双脚自然站立，脚趾与脚背完全裸露，无鞋袜
7. **配饰**：发间点缀一枚小巧可爱的发饰；颈间佩戴一条项链，坠饰静静垂于锁骨下方的亚麻上衣前襟处，呼应可爱与古希腊的双重气质
