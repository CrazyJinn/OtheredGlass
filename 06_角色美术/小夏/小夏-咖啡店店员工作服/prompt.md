# 着装提示词

## 着装

1. **开头声明**：角色立绘设计图，纯绿色背景（chroma key green，#00FF00），全身三视图（正面、侧面、背面三个视角并排展示，同一角色三个视角保持外观一致，每个视角完整展示全身）
2. **着装款式**：整体着装风格可爱而休闲。上身内层穿奶油白棉质短袖女衬衫，圆领剪裁干净，袖口滚浅粉边；下身套一条米色棉质 A 字过膝裙，裙摆自然散开；外面系一条浅粉亚麻及膝围裙，围裙正面胸口处有一个贴袋，腰后在身后系成蝴蝶结
3. **材质质感**：衬衫为棉质，布面平滑亲肤、垂坠柔软；围裙为亚麻织物，带细腻的天然纹理感；A 字裙同为棉质，挺括又保有柔和的裙型轮廓
4. **配色**：着装配色以奶油白为主色用在衬衫，浅粉为辅色用在围裙、袖口滚边与发夹，米色点缀在 A 字裙，整体呈柔和的暖色调
5. **鞋袜**：脚穿帆布鞋，鞋型轻便休闲
6. **配饰**：头发一侧别一枚浅粉小发夹

## 画风

1. **画面类型**：角色立绘设计图，全身三视图，静态站姿，双手自然垂于身侧
2. **背景**：纯绿色背景（chroma key green，#00FF00）
3. **线条**：细到中等线稿，外轮廓线略粗，内部结构线较细，面部线条极细，线条干净利落、略柔和，平滑干净无纹理，线条颜色深棕至近黑
4. **上色与光影**：平涂（Flat-shading），干净色块，分层平涂阴影，阴影边缘半硬边（比硬边赛璐璐略柔，带轻微渐变过渡），明暗对比中等，单主光源，环境光弱，高光简洁点缀，皮肤轻微渐变过渡（非纯平面）；分辨率 1024 × 1024
5. **比例**：7.5 头身，身材比例匀称
6. **色调**：清爽高级，色温中性偏暖，饱和度中等，色彩对比中等（靠明暗与色块层次）
