# 设计图提示词

## 画风

1. **画面类型**：角色设计图，全身三视图（正面、侧面、背面三个视角并排展示，同一角色三个视角保持外观一致，每个视角完整展示全身）
2. **背景**：纯绿色背景（chroma key green，#00FF00）
3. **线条**：细到中等线稿，外轮廓线略粗，内部结构线较细，面部线条极细，线条干净利落、略柔和，平滑干净无纹理，线条颜色深棕至近黑
4. **上色与光影**：平涂（Flat-shading），干净色块，分层平涂阴影，阴影边缘半硬边（比硬边赛璐璐略柔，带轻微渐变过渡），明暗对比中等，单主光源，环境光弱，高光简洁点缀，皮肤轻微渐变过渡（非纯平面）；分辨率 1024 × 1024
5. **比例**：7.5 头身，身材比例匀称
6. **色调**：清爽高级，色温中性偏暖，饱和度中等，色彩对比中等（靠明暗与色块层次）

## 角色设定

1. **体型**：身高约 165cm，体型匀称，整体轮廓以圆形形状语言为主，肩线柔和，身形呈现清新软糯的邻家少女气质，静态站姿，双手自然垂于身侧
2. **面部**：中国面孔，圆润的苹果脸配尖下巴，一双深棕色圆杏眼，眼神清澈明亮，微笑唇，唇角自然微弯，肤色健康粉，双颊带浅粉腮红，少女年龄感，默认表情是恬静的浅笑，透出元气少女感，甜而不腻，第一印象是软萌咖啡店店员
3. **发型**：栗色齐肩微卷发，发尾自然外翘，配薄薄的空气刘海，碎发轻软地贴在额前，发丝质感柔软蓬松
4. **贴身基础衣物**：穿着黑色贴身背心与深色短裤，与肤色形成高对比，不涉及服装设计细节
5. **外貌配色**：栗色头发呈暖栗棕色调，深棕色瞳孔，健康粉肤色辅以浅粉腮红，整体外貌配色像一杯加了奶的拿铁，奶油般甜暖不腻
6. **特殊标记**：无明显疤痕、纹身、胎记或身体异征
