# 设计图提示词

## 画风

1. **画面类型**：角色设计图，全身三视图（正面、侧面、背面），三个视角并排展示，同一角色三视角保持外观一致，每个视角完整展示角色全身设计
2. **背景**：#00FF00 纯绿色背景（chroma key green）
3. **线条**：细线稿，外轮廓线略粗，内部结构线较细，面部线条极细，线条变化中等，圆润柔和，光滑干净，纯黑色
4. **上色与光影**：半厚涂上色，Anime Illustration 主体渲染，软阴影，柔和渐变边缘，低明暗对比，单主光源，弱环境光，中等偏弱高光
5. **比例**：7.5 头身，半写实（写实度 6.5/10），动画风 70% + 写实风 30%，轻小说封面风
6. **色调**：暖色调，偏暖色温，中低饱和度，低色彩对比

## 角色设定

1. **体型**：身高约 170cm，曼妙丰腴的修长身段，肩颈线条纤长，锁骨清晰可见，腰线收束，整体呈现成熟御姐的曼妙曲线，体型以圆形为形状语言，圆润饱满而富有成熟女人味。静态站姿，双手自然垂于身侧，躯干略带慵懒的微挺胸姿态，气质疏离而勾人
2. **面部**：脸型小巧精致，下颌线锐利，眉眼含情，红色上挑眼，眼尾微微挑起带几分妩媚，眼瞳呈深红色，唇形饱满，唇角天然微翘带几分慵懒，瓷白肌肤。默认表情是慵懒妩媚、眼神疏离而勾人的成熟女性气质，第一印象是一个让人移不开眼却不敢轻易靠近的女人
3. **发型**：红色微卷长发，披散至肩下，发质光泽，发丝在光线下泛着红色光泽，带有自然的微卷弧度
4. **贴身基础衣物**：穿着黑色贴身背心与深色短裤，与瓷白肤色形成高对比，仅作为基础衣物展示体态，不涉及服装设计细节
5. **外貌配色**：主色为红色微卷长发与暗酒红氛围，辅色为瓷白肌肤与冷灰，点缀色为深红的瞳色。配色逻辑为红发作为视觉焦点统领气场，瓷白肌肤作高对比留白凸显红发红瞳的强烈色彩，深红瞳色强化危险而诱惑的眼神，整体呈现夜间都市的疏离与诱惑感
6. **特殊标记**：无
