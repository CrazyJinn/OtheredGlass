# 设计图提示词

## 画风

1. **画面类型**：角色设计图，单张图片并排展示正面、侧面、背面三个视角的全身三视图，三个视角外观与气质保持一致；韩系平涂角色插画（Korean Flat-shading Illustration）风格，参考韩国商业插画与韩系手游角色美术的清爽精致质感，写实度 6/10（写实风 40% + 动画风 60%），以干净色块、清爽配色与精致细节呈现现代商业插画的平面美感。
2. **背景**：纯绿色背景（chroma key green，#00FF00）。
3. **线条**：干净的细到中等线稿，线条为深色（深棕 / 近黑）、粗细有变化（外轮廓略粗、细节纤细），线条干净利落但略柔和，呈现代商业插画的精致勾线感。
4. **上色与光影**：平涂（flat-shading）上色为主，色块干净平整；阴影为清晰的分层平涂阴影，但阴影边缘比硬边赛璐璐略柔（半硬边 / 带轻微渐变过渡），层次分明；皮肤有轻微渐变过渡（非纯平面），整体清爽精致；单一主光源，高光简洁点缀。
5. **比例**：7.5 头身的修长比例，肩颈纤长、四肢舒展、腰线清晰，保留精致的美化与时尚感。
6. **色调**：暖红调（酒红发色统领，瓷白肌肤为高光），清爽高级的配色，饱和度中等，色彩干净和谐、有现代商业插画的设计感，整体明亮通透。

## 角色设定

1. **体型**：身高约 170cm，曼妙匀称的修长身段，丰腴而紧致的曲线，倒三角的形体语言（肩线相对舒展、腰线清晰收窄），肩颈线条纤长，锁骨清晰可见；三个视角均呈静态站姿，双手自然垂于身侧，不出现交叠、叉腰或持物等动态手部动作，成熟妩媚的体态气质通过肩线、重心与躯干姿态体现。
2. **面部**：中国面孔，成熟的御姐气质，眉眼含情，酒红色的丹凤眼配深红酒红瞳色，唇形饱满，唇角天然微翘带着几分慵懒，默认神情是慵懒妩媚与冷调疏离的混合，透出一丝危险的诱惑。
3. **发型**：酒红色的法式大波浪长发，垂落肩头，发质润泽光泽，带有自然的波浪弧度与少量碎发细节。
4. **贴身基础衣物**：角色穿着深色基础衣物（黑色贴身背心搭配深色短裤），与瓷白肤色形成高对比，仅用于展示体态与外貌，不涉及具体服装设计细节。
5. **外貌配色**：整体笼罩红色与暗酒红的氛围色调，瓷白肌肤作为高对比留白，凸显酒红瞳色勾人而危险的眼神；酒红色法式大波浪长发作为视觉焦点统领气场，深红瞳色强化危险而诱惑的眼神，整体呈现夜间都市的疏离与诱惑感。
6. **特殊标记**：眼角有一颗泪痣。

## 风格关键词

韩系平涂，Korean Flat-shading Illustration，韩系商业角色插画，干净色块，清爽高级配色，精致勾线。
