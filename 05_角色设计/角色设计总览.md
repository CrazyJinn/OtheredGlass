# 角色设计总览

## 美术通用设定

> 从 CLAUDE.md 和世界设定中提取，所有角色设计共享的美术基础。

### 美术方向

```
2D动漫风格 / 现代都市 / 半厚涂质感
现代中国都市背景，以重庆为城市原型，色调偏写实但不失动漫感
```

### 玩家视角

2D对话游戏 / 立绘 + 对话框 / 第一人称代入
