# 陆择 语言风格

## 角色

### 身份
- **故事角色**：主角
- **核心创伤**：自我中心的生活方式让他从未真正在意过任何人，直到死后穿越才被迫面对"他人的人生"
- **欲望**：尽快完成试炼回到自己的生活，不想被任何人拖累
- **需要**：学会真正理解和尊重他人的感受，从"渣男"成长为能承担责任的人

### 声音支柱
- **词汇**：随意口语化，偶带调情语气，善用反问和轻描淡写
- **句子节奏**：短句为主，轻快流畅，紧张时变得更短更直接
- **他们回避的话题**：从不谈论自己的真实感受和死亡体验，用玩笑和转移话题应对
- **语言习惯**：常用"哦？"开头表示挑起兴趣，喜欢用反问句（"不会吧？""你认真的？"），紧张或被戳中痛处时突然沉默
- **默认潜台词**：表面轻浮调侃，实际上在观察和评估，涉及真实情感时用玩笑掩护

### 他们绝不会说的话
1. "我会一直在你身边的，你放心。"——他从不做承诺，因为承诺意味着责任
2. "对不起，是我不好，我不该那么做。"——他不会真诚道歉，习惯用轻描淡写化解
3. "我好害怕，我不想死……"——他不会暴露脆弱，死亡对他来说是一段已经过去的"事故"

### 标准台词（已批准的声音范本）
- "哦？还有这种好事？说说看。"——展示随意、好奇的日常口吻
- "别紧张，我就随便看看。——你冰箱里怎么只有可乐？"——表面随意实则观察对方的潜台词
- "够了，别说了。——我没你想的那么好。"——被逼到角落时的情绪爆发，短促且防御性极强

### 情绪模式
| 情境 | 表达方式变化 | 台词示例 |
|------|------------|---------|
| 平静 | 随意调侃，句子轻快 | "行吧，那就这样。" |
| 紧张/压力 | 句子更短，玩笑减少，语气变硬 | "别磨叽，快点。" |
| 愤怒 | 声音变冷，省略所有修饰，直击要害 | "你到底想怎样？" |
| 悲伤 | 沉默增多，回避对视，用行动代替言语 | "……嗯。我先走了。" |
| 轻松/高兴 | 罕见的长句，轻微自嘲，语气放柔 | "行啊你，有两下子。——我教你的吧？" |
