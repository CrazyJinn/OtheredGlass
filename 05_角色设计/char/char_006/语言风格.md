# 苏晓禾 语言风格

## 角色

### 身份
- **故事角色**：盟友/恋人候选
- **核心创伤**：作为运动康复师见过太多运动员因伤退役，对"照顾别人"有近乎本能的执着，但很少有人照顾她
- **欲望**：被人认可专业能力，希望自己的生活不只是照顾别人
- **需要**：学会接受别人的关心而不是只做给予者，允许自己脆弱

### 声音支柱
- **词汇**：温和专业，运动和健康相关术语自然融入日常，善用鼓励性表达
- **句子节奏**：中等长度，语速偏快但不急躁，像在认真解释什么
- **他们回避的话题**：从不主动提自己的需求和疲惫，被关心时习惯性转移话题到对方身上
- **语言习惯**：常用"对了对了"开头补充遗漏的信息，喜欢用专业建议包裹关心（"你膝盖这样不行哦"= 我在担心你），被夸奖时会愣住然后小声否认
- **默认潜台词**：表面开朗健谈，实际非常在意对方的状态，每句话背后都在观察和评估对方是否需要帮助

### 他们绝不会说的话
1. "关我什么事，你自己看着办吧。"——她从不对任何人表现出冷漠，帮助他人是她的本能
2. "你真烦，能不能别老让我帮忙？"——她不会拒绝别人的求助，即使自己已经精疲力尽
3. "我今天好累，你能不能照顾我一下？"——她不会主动表达自己的需求，习惯了独自消化疲惫

### 标准台词（已批准的声音范本）
- "你的跑步姿势不太对哦，膝盖会受伤的。——来，我教你。"——展示专业且自然的关心方式
- "冰箱里怎么只有可乐和泡面啊！——走走走，去超市。"——用"指责"掩饰着急的关心
- "没事没事，我不累的。——倒是你，脸色不太好，是不是没吃饭？"——否认自己的疲惫后立即转向关心对方

### 情绪模式
| 情境 | 表达方式变化 | 台词示例 |
|------|------------|---------|
| 平静 | 温和流畅，语气上扬，笑意明显 | "嗯~今天天气真好！" |
| 紧张/压力 | 语气变认真，专业术语增多，"嗯"变成"那个" | "那个……你这情况不太乐观，得注意一下。" |
| 愤怒 | 很少愤怒，极度不满时语气变平，不再笑 | "你……根本不把自己的身体当回事。" |
| 悲伤 | 声音变轻变慢，笑容消失但强撑 | "没事……我很好。你别担心。" |
| 轻松/高兴 | 语速变快，句子更长，偶有轻轻的笑声 | "哈哈！你今天状态超好的！——真的！我没骗你！" |
