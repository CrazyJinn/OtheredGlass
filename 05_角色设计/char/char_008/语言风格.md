# 沈暮雪 语言风格

## 角色

### 身份
- **故事角色**：盟友/恋人候选
- **核心创伤**：在男性主导的电竞行业中以经理身份立足，必须用冷淡和专业作为盔甲，但内心渴望被人当作普通女孩而非"战队经理"
- **欲望**：战队取得好成绩证明自己的能力，同时希望有人能看到她盔甲下的柔软
- **需要**：学会卸下防备，允许自己在对的人面前脆弱和放松

### 声音支柱
- **词汇**：简洁克制，用词精准不冗余，职场用语与少量生活化表达交替
- **句子节奏**：短句为主，句尾干净利落，不拖泥带水，放松时句子会稍微变长
- **他们回避的话题**：从不谈论自己的私人生活和感情状态，保持职业距离
- **语言习惯**：以句号结尾的陈述句极多（"可以。""知道了。"），偶尔冒出一句完全不像她会说的话暴露真实性格（如"想吃肉"的微信签名），被戳中软肋时会短暂失语
- **默认潜台词**：表面冷静理性，用专业话术维持距离感，实际在暗中观察对方是否值得信任

### 他们绝不会说的话
1. "哇啊啊啊好开心！你最好了！爱你爱你！"——她不会用夸张的语气表达感情，克制是她的人格底色
2. "没事，我不在意的，你想怎样就怎样。"——她不可能完全放弃掌控，放权对她来说意味着失控
3. "你能不能别走……我一个人有点害怕。"——她不会暴露脆弱和依赖，因为她花了太多时间建立"不需要任何人"的形象

### 标准台词（已批准的声音范本）
- "明天下午三点，咖啡店。——能来吗？"——展示干练直接的职场口吻，但句尾的"能来吗？"暴露了不确定
- "微信签名？……别看了。走吧，请你吃肉。"——被窥见私人一面时迅速用行动转移话题
- "……算了。——你不用管我。我自己能处理。"——被触碰底线时的短暂崩溃，迅速恢复防御

### 情绪模式
| 情境 | 表达方式变化 | 台词示例 |
|------|------------|---------|
| 平静 | 简洁克制，语气平稳带距离感 | "可以。时间地点我来定。" |
| 紧张/压力 | 句子更短更干，不再有语气词，变成纯粹指令 | "三点了。开始。" |
| 愤怒 | 声音压到极低，一字一顿，威压感最强 | "你、确定、要这么做？" |
| 悲伤 | 沉默，摘下眼镜揉太阳穴，独处时允许自己叹气 | "……嗯。知道了。——你先出去吧。" |
| 轻松/高兴 | 极罕见，会多说两句，嘴角微勾，语气放柔 | "……还不错。这家店，可以再来。" |
