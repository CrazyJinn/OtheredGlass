# 顾盈 语言风格

## 角色

### 身份
- **故事角色**：过客（开场功能性角色）
- **核心创伤**：不曾被谁真正记住——她习惯了做别人清晨醒来后第一个想不起来的人，这种"不被在意"让她学会了先一步离开
- **欲望**：享受当下，不留纠缠，在每一次邂逅中保持主动权
- **需要**：被人真正看见，而非只是被欲望的对象

### 声音支柱
- **词汇**：随意、轻佻但不粗俗，口语化中带着从容，偶尔用暧昧的双关但不刻意
- **句子节奏**：短句为主，语速慢而从容，停顿多，像在享受说话本身
- **他们回避的话题**：从不谈论自己的名字以外的事，不提工作、家庭、住处——任何能被追踪到的信息
- **语言习惯**：喜欢用反问收尾（"嗯？""是吗？"），笑意藏在话尾，沉默时比说话更有存在感
- **默认潜台词**：表面上漫不经心、什么都不在乎，实际上每一句话都在掌控对话的节奏和距离

### 他们绝不会说的话
1. "你以后还会联系我吗？"——她绝不会主动要联系方式，这等于承认在意
2. "我其实挺孤独的"——她不会展露脆弱，尤其在陌生人面前，孤独对她来说是失态
3. "你是第一个对我好的人"——她不会把任何人特殊化，这等于交出主动权

### 标准台词（已批准的声音范本）
- "衬衫不还你了啊——反正你也不缺这一件。"——展示随意和掌控感，把"拿走你的东西"说得像在帮你
- "别紧张，我又不会吃了你。嗯……可能会？"——展示暧昧双关和调侃，用玩笑拉近距离又随时能抽身
- "走了。趁我还记得你的好。"——展示压力/告别场景，用"记得你的好"制造一个体面又暧昧的收尾，不给自己留回头路

### 情绪模式
| 情境 | 表达方式变化 | 台词示例 |
|------|------------|---------|
| 平静 | 语速慢，句子短，笑意缀在话尾 | "嗯，水挺热的。" |
| 紧张/压力 | 语速更慢，停顿变长，用沉默代替回应 | "……你的手机。" |
| 愤怒 | 声音变冷，省去所有缀词，句子极简 | "别碰我。" |
| 悲伤 | 沉默增多，主动结束对话，笑容不变但眼神空了 | "走了。——嗯，再见。" |
| 轻松/高兴 | 罕见的长句，轻微自嘲，语调上扬 | "今天阳光不错，难得你还在。" |
