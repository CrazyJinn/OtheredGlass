# 江烈 语言风格

## 角色

### 身份
- **故事角色**：对手/竞争者
- **核心创伤**：带领战队多年却始终未能突破瓶颈，对个人实力极度自信但对团队配合充满焦虑
- **欲望**：带领战队夺得冠军，证明自己的战队管理能力
- **需要**：学会信任队友而不是事事亲力亲为，接受团队协作中的不完美

### 声音支柱
- **词汇**：直接简短，军事化指令式表达，不用形容词，善用否定句
- **句子节奏**：极短，指令式，三五个字解决问题，不拖泥带水
- **他们回避的话题**：从不谈论战队成绩下滑的压力和个人状态的焦虑
- **语言习惯**：以动词开头的祈使句极多（"过来""坐下""别说"），夸人时用"还行"代替"很好"，生气时一字一顿
- **默认潜台词**：表面强硬不讲情面，实际对战队和队友有极强的保护欲，但不会用语言表达关心

### 他们绝不会说的话
1. "哎呀没关系的，输了就输了嘛，重在参与~"——他对胜负有极端的执念，绝不可能轻描淡写
2. "对不起，刚才是我态度不好，你愿意跟我聊聊吗？"——他不会主动道歉或示弱，情感表达极其笨拙
3. "我其实挺害怕的，万一这次又输了怎么办……"——他绝不在任何人面前暴露恐惧，恐惧等于软弱

### 标准台词（已批准的声音范本）
- "别废话。打一把看看。"——展示直接、结果导向的日常口吻
- "还行。——但你跟不上节奏就别硬撑，拖后腿我可不客气。"——"还行"已经是他最大的认可，后半句暴露了他的团队焦虑
- "我说最后一遍——这事我说了算。不服？走人。"——高压下的强硬表态，用威压掩盖内心的不安

### 情绪模式
| 情境 | 表达方式变化 | 台词示例 |
|------|------------|---------|
| 平静 | 极简短句，语气平稳 | "行。就这个。" |
| 紧张/压力 | 语速加快，句子更短，频繁下指令 | "跟上。别停。快点。" |
| 愤怒 | 一字一顿，声音压低但压迫感极强 | "你、再说、一遍。" |
| 悲伤 | 彻底沉默，独处时猛灌水或反复擦拭设备 | "……不用管我。去训练。" |
| 轻松/高兴 | 极罕见，会短暂多说两句，语气放松但仍然很简短 | "不错。这波配合——还行吧。" |
