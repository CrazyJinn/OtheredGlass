# 章节设计简报方法论

> 本 skill 产出 `25_剧本/chapter<NN>_设计简报.md`，含四节（设计支柱 / 情感弧线 / 戏剧意图 / 核心循环）。本文件指导每节怎么写——方法论摘自游戏/叙事设计理论，适配 galgame 章节。

## 设计支柱（3–5 个不可妥协的体验目标）

设计支柱是本章**必须传递**的玩家体验——后续每个创作决策（选哪些 Scene、排什么序、下游写什么对话）都以支柱为标尺。少了它们本章就不成立。

怎么定：
- 从玩家动机出发，不从功能清单倒推。每个支柱回答"玩家此刻的感受是什么？他们在做什么决策？"
- 3–5 个，不可妥协。多了等于没有。
- 一句话表述一个**体验**，不是机制。

galgame 章节支柱示例（仅供体感，非模板）：
- "让玩家理解主角对死亡的疲惫"
- "建立与某配角的暧昧张力"
- "让某个选择显得沉重到玩家犹豫"

> 反模式：把支柱写成功能（"本章有 3 个分支"）——那是结构不是体验。

## 情感弧线（情绪起点→终点）

玩家在本章情感上从哪里出发、到哪里结束。不是事件清单，是**情绪轨迹**。

- 映射弧线：起点情绪 → 中段起伏（turning point）→ 终点情绪。
- 与设计支柱对齐：弧线的终点应达成或反转某个支柱承诺的体验。
- 标注关键转折点（哪里情绪翻转）——下游 outliner 排 scene 节奏时对齐它。

## 戏剧意图（本章在整部作品里的任务）

本章存在的**戏剧理由**——不是"发生了什么"，而是"为什么必须有这一章"：

- **建立**：建立什么关系 / 设定 / 悬念？
- **转折**：转折什么（角色弧、玩家认知、关系）？
- **收束**：收束什么（支线、伏笔、情感）？

一句话**核心主题问题**：本章向玩家提出的、贯穿始终的问题（如"为了陌生人值得牺牲自己吗"）。下游 dialoguer 写对话时回看它保持主题一致。

## 核心循环（galgame 适配）

galgame 不是数值循环，但仍有体验循环层次。为本章定义三层：

- **即时体验段（一句对话 / 一个选择，0–30 秒）**：玩家在做什么微动作？反馈是什么？（读一句、做一个选择、看到一张立绘变化）
- **本章节目标（5–30 分钟）**：玩家本章想完成什么？（看完这段剧情、达成某个结局、了解某个角色）
- **长期留存钩子（跨章节）**：本章埋下什么让玩家想继续？（悬念、关系发展、未解之谜）

> 核心循环帮 structurer 检查"本章在每个时间尺度上都有事可做"，避免章节只在单一尺度上运作。
