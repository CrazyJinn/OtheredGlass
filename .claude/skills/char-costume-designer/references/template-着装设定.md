# 着装设定模板

> 为角色的事件场景设计着装方案，写入 CostumeStyle 图节点。
> Schema 定义见 `00_init/Schema/角色美术.md`。

---

## 各字段规则

**默认着装**：根据事件环境设计的完整着装描述，用逗号分隔单品 → `CostumeStyle.default_outfit`

**材质方向**：2-4种主要材质，含质感描述（哑光/光泽、粗糙/光滑），与阵营风格一致 → `CostumeStyle.material_direction`

**体态气质**：与着装场景匹配的体态。站姿必须是可用于设计图三视图的**静态站姿**（肩线、重心、含胸/挺胸、躯干状态），禁止包含持物、叉腰、交叠等手部动作。手部动作和标志性道具留给立绘和精灵帧表现 → `CostumeStyle.posture`

**配饰**：与着装搭配的配饰和标志性道具（眼镜、手表、耳饰等） → `CostumeStyle.accessories`

---

## 反例：体态气质中的持物描述

体态气质中混入手部动作和持物描述，会导致下游设计图提示词违规（设计图仅允许静态站姿，禁止持物）。

**错误写法**：
```
## 体态气质
- **站姿**：笔直优雅，双臂自然交叠或单手持咖啡杯，气场强大
```

**正确写法**：
```
## 体态气质
- **站姿**：笔直优雅，重心居中，肩线平直，气场强大
- **动作风格**：动作精准克制，常单手持咖啡杯（立绘/CG表现）
```

标志性道具（咖啡杯、水壶、手账本等）放在**配饰**中并标注"(立绘/CG表现)"，不写入站姿描述。
