# 场景背景提示词模板（SceneLayer / background）

> background 层通过**文生图**方式生成，是场景的完整背景图（远中近景）。
> dialogue/ui 场景的唯一图层；functional/combat 场景的最底层。
> 数据来源：Scene 节点字段 + Location 名 + 00_init/美术风格.md。

---

## 输出模板

```markdown
# 场景背景提示词

## 用途与主体
<!-- 数据来源：scene_type（用途前缀）+ location.name + scene.name + atmosphere + time_of_day + weather -->

[用途前缀]，[场景空间的自然语言描述]，[时间与天气]，[整体氛围]。

## 环境（远中近景）
<!-- 数据来源：scene.composition -->

远景可以看到[远景的连贯描述]，中景是[中景的连贯描述]，近景是[近景的连贯描述]。

## 光影
<!-- 数据来源：scene.lighting + scene.camp（阵营配色查表） -->

主光源从[方向]照射，呈现[颜色]色调，环境光[描述]。

## 风格
<!-- 数据来源：scene.color_direction + scene.art_element + 美术风格.md -->

[配色逻辑]，[风格元素]，油画风格，手绘质感，游戏美术，无角色
```

## 用途前缀（按 scene_type）

| scene_type | 用途前缀 | 构图要点 |
|-----------|---------|---------|
| `dialogue` | 游戏对话背景图 | 构图简洁，不干扰角色立绘，可适当模糊 |
| `functional` | 游戏场景背景图 | 功能区域清晰 |
| `combat` | 游戏场景背景图 | 房间后方元素为主，留出战斗空间 |
| `ui` | 游戏UI背景 | 极简，不干扰 UI 阅读 |

| 教会（魔法） | 金/白 | 金色、圣光 | 庄严、神圣、宗教 |
| 废土 | 黄褐/灰 | 橙红、灰暗 | 荒凉、危险、末世 |
| 变异森林 | 绿/紫 | 绿色、暗紫 | 阴森、变异、危险 |

## 各 scene_type 完整示例

### dialogue（对话背景）

```
游戏对话背景图，[Location名]的[Scene区域]，[时间与氛围]。
远景是[简化的远景描述]，中景是[简化的中景描述]，近景是[模糊的近景描述]。
主光源从[方向]照射，环境光[柔和描述]。
[风格元素]，油画风格，手绘质感，游戏美术，做旧处理，简洁构图，突出角色立绘，无角色
```

**要点**：构图简洁不喧宾夺主，可适当模糊，保持氛围感但不干扰角色立绘。

### functional / combat（游戏场景）

```
游戏场景背景图，[场景主题的完整描述]，[功能区域]，[氛围的自然语言描述]。
远景可以看到[远景元素]，中景是[中景元素]，近景是[近景元素]。
主光源从[方向]照射，呈现[颜色]色调，环境光[描述]。
[风格元素]，油画风格，手绘质感，游戏美术，无角色
```

### ui（UI背景）

```
游戏UI背景，[界面名称]，[风格的自然语言描述]，[装饰元素的描述]。整体主色调为[颜色]，环境光[描述]。
油画风格，手绘质感，游戏美术，做旧处理，简洁不干扰UI元素
```

---

## 编写要点

1. **自然语言优先**：用完整描述句，而非逗号关键词
2. **用途开头**：提示词开头声明用途（游戏对话背景图 / 游戏场景背景图 / 游戏UI背景）
3. **远中近景分层**：composition 的三段各写成连贯句子
4. **光影匹配氛围**：光源方向与颜色与氛围一致；阵营配色融入光效
5. **风格词放末尾**：风格元素 + 「油画风格，手绘质感，游戏美术」
6. **必须含「无角色」**：场景图不出现角色
7. **只提取不创作**：所有内容来自 Scene 字段与美术风格.md，不臆造
