# 声音设计模板（VoiceProfile instruct / ref_text 写作指南）

本模板指导 char-voice-design 第 2 步：把角色的叙事素材（Character 基础属性 + LanguageStyle + Info + Event）转写成 Qwen VoiceDesign 能理解的 `instruct` 自然语言，以及固化音色的 `ref_text`。

## instruct：一段覆盖六维的自然语言

**写成一段连贯的中文描述**（不是键值对、不是 bullet），让 VoiceDesign 模型像读角色小传一样理解音色。六维都要落到字面：

| 维度 | 怎么写（典型词） | 素材来源 |
|------|------------------|----------|
| **性别** | 「青年男性」「成熟女性」「少年」 | `Character.gender` + age_impression |
| **年龄** | 「20余岁」「约28岁」「少女」 | `Character.birth_year`（算岁数） |
| **音色** | 中低音/中音/高音 + 沙哑/清亮/圆润/清冷/浑厚 | `description` + `character_tags` + Event 经历（沧桑感） |
| **气质** | 玩世不恭/冷漠疏离/温柔/傲慢/气定神闲/沉郁 | `character_tags` + `LanguageStyle.description` + Info 深层身份 |
| **语速** | 「语速不快」「语速不疾不徐」「短促急迫」 | `LanguageStyle.rhythm`（短促→快 / 长句思考→慢） |
| **尾音** | 「尾音常带一丝玩味的上扬」「尾音果断收束」「拖音犹豫『嗯…』」 | `LanguageStyle.habits`（口头禅/犹豫模式）+ `emotion_patterns` |

### 写作要点

- **气质是核心**：音色服务于气质。先用 character_tags / Info 定气质底色，再配音色厚度与语速尾音去强化它。
- **尾音要有画面**：尾音是角色辨识度最强的维度，直接从 `LanguageStyle.habits` 的口头禅/犹豫模式里提炼（如习惯拖「嗯……」→ 尾音拖音；爱反问 → 尾音上扬）。
- **经历渗入音色**：`Event` 里 `type=转折/状态变化` 的重大经历（创伤/失去/蜕变）可让音色带沧桑/疲态/冷硬；`Info` 的 `knowledge_level=2,3` 深层身份（孤儿/隐情/创伤）塑气质底色。表层信息（`knowledge_level=1` 新闻类、`type=行动/交流` 日常事件）参考价值低，可略。
- **一段话写完**：自然语言衔接，避免机械罗列。可在最后补一句「表面 X，底下 Y」点出层次。

### 反模式（避免）

- ❌ 只写「男声，低沉」——缺气质/语速/尾音，VoiceDesign 出来的音色没辨识度。
- ❌ 写成键值对 `性别:男 / 音色:低沉 / ...`——VoiceDesign 要自然语言叙述。
- ❌ 照搬立绘视觉词（「三角型脸」）——视觉词对音色无信号，转成音色语义（细长型→清冷）。
- ❌ instruct 里写情绪台词内容——instruct 只描述音色，台词由 ref_text / 实际配音承载。

## ref_text：一句固化音色的参考句

- **10-20 字**，单句，贴近角色典型语气。
- 要能**一句话听出是谁**：体现 instruct 的腔调（慵懒/从容/冷漠/急切）。
- 内容**无所谓剧情**（不对外、不进运行时），只为触发 VoiceDesign 合成该音色的 ref_audio。
- 若 `LanguageStyle.description` 有「标准台词」字段，可直接化用。

## 范例

### 陆择（玩世不恭的调侃腔）

- **instruct**：`青年男性，20余岁，中低音略带沙哑；玩世不恭的调侃腔调，嘴角噙笑、语气松弛慵懒，像用渣男口头话把真实情绪裹起来；语速不快，尾音常带一丝玩味的上扬；表面从容，底下偶有一沉。`
- **ref_text**：`嗯……这床是真不行，我都怕它散架。`
- **description**：`玩世不恭的调侃腔，中低音略沙哑（依据 06_角色美术 立绘变体 轻佻/沉吟）`

### 顾盈（成熟从容的玩味反撩）

- **instruct**：`成熟女性，约28岁，中音略偏低、嗓音圆润；气定神闲、似笑非笑的玩味腔调，从容笃定中暗藏锐利；是被撩也能反撩的对手，松弛慵懒却始终掌控节奏；语速不疾不徐，尾音常带一丝戏谑的上扬；表面温和随性，底子自信而漫不经心。`
- **ref_text**：`哟，这才醒啊——咖啡都凉了，我可没等你。`
- **description**：`成熟从容的玩味反撩，中音略偏低（依据 06_角色美术 立绘变体 挑眉/玩味/慵懒）`

> 两个范例的尾音描述（「玩味的上扬」「戏谑的上扬」）都直接源自 LanguageStyle 的 habits/语气——证明文字风格与音色同源。
