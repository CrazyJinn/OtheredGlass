# 角色立绘提示词模板

> 立绘通过**图生图**方式生成，基于 IllusDesign.image_path（立绘设计图）作为参考。提示词描述全身立绘，包含表情、手部动作和脚部动作，不重复角色外观和着装。
> 表情参考 LanguageStyle 节点的 `emotion_patterns` 字段（情绪模式）和 `description` 字段（概要）。

## 变体数量规则

根据角色优先级决定变体数量：

| 优先级 | 变体数 | 变体内容 |
|--------|-------|---------|
| P0（主角） | 10 | 默认、微笑、愤怒、悲伤、惊讶、思考、坚定、恐惧 + 战斗姿态 + 负伤状态 |
| P1（核心 NPC） | 6 | 默认、微笑 + 4个角色专属表情 |
| P2（一般 NPC） | 2 | 默认、微笑 |

### 表情选择原则

1. **通用表情**（默认、微笑）所有角色都包含
2. **角色专属表情**根据角色语言风格中的情绪模式定制
3. **战斗姿态**和**负伤状态**仅 P0 角色包含
4. 表情应覆盖角色在剧本中最常出现的情绪状态

## 编写要点

### 核心原则

1. **不重复外观和着装**：立绘基于设计图生成，提示词不描述服装、发型、体型、配饰等
2. **描述身体朝向、表情、手部动作和脚部动作**：全身立绘需要完整描述身体面对镜头的朝向、表情、手部和脚部的姿态
3. **参考情绪模式**：表情描述应与 LanguageStyle.emotion_patterns 中的情绪模式一致，description 概要辅助理解角色
4. **身体朝向由氛围决定**：依据变体情绪自主选择身体面对镜头的朝向（正视镜头/3/4侧身/全侧身/背影），不要所有变体都僵化地正面朝向
5. **动作幅度可更大、更有张力**：除「默认/微笑」等静态变体外，应大胆使用大幅度动态姿态（挥臂/跨步/转身/前倾/跃起），避免每个变体都是拘谨的小幅站姿；动态变体的手脚动作要拉开幅度以强化情绪

### 描述要素（身体朝向 + 表情 + 动作）

- **身体朝向（LLM 据氛围自主选）**：正视镜头/3/4侧身/全侧身/背影。倾向参考：默认/微笑 → 正视镜头；战斗/愤怒/惊讶 → 3/4侧身；回眸/远眺/悲伤 → 全侧身或背影
- **眼部**：睁大/微闭/下垂/锐利
- **眉毛**：上扬/紧锁/舒展/内八字
- **嘴部**：微笑/紧抿/微张/咬牙
- **面部肌肉**：放松/紧绷/抽搐
- **头部角度**：正视/微侧/上扬/低垂
- **手部动作**：自然垂放/叉腰/握拳/单手托腮/持物/交叉胸前/前伸/一手插兜/双手背后/抱臂/大幅挥动/单臂上举/双臂张开/转身回眸手势/双手撑膝/单臂前伸指人/双手插袋斜倚
- **脚部动作**：并拢/前后开立/单脚微抬/跨步/脚尖内扣/外展/重心偏移/大跨步/弓步/单腿交叉前伸/踢腿前摆/重心大幅前倾/跃起腾空

### 手部动作选择原则

1. **默认/微笑**：自然、放松的小幅手部姿态（自然垂放、轻触颈侧等）
2. **战斗/愤怒**：大幅力量感姿态（单臂上举握拳、大幅挥动、双臂张开等）
3. **悲伤/负伤**：自我保护姿态（捂伤口、抱臂、单手托腮等）
4. **惊讶/恐惧**：紧张或退缩的大幅姿态（双臂张开、双手前伸挡、交叉胸前等）
5. **思考/坚定**：沉稳姿态（一手托腮、双手背后、双手撑膝等）

### 脚部动作选择原则

1. **默认/微笑**：稳定站姿（并拢、自然站立）
2. **战斗/愤怒**：大幅战斗站姿（大跨步、弓步、重心下沉）
3. **悲伤/负伤**：不稳定站姿（微张勉强站稳、重心偏移）
4. **惊讶/恐惧**：后退或紧张姿态（单脚微抬、脚尖内扣、重心后移）
5. **行走/动态**：大跨步、跃起腾空、重心大幅前倾

### 提示词固定格式

- 前缀：`[角色名称]立绘，[从美术风格.md 读取背景色]背景，全身像，`
- 身体朝向：`[身体面对镜头的朝向]`（紧接「全身像」之后，LLM 据氛围自主选定：正视镜头/3/4侧身/全侧身/背影）
- 表情+动作描述：`[头部角度]，[表情细节]，[手部动作]，[脚部动作]`
- 风格标签：从 `00_init/美术风格.md` 读取（不使用固定后缀）

### 每个变体独立生成

每个表情变体使用独立提示词，确保各变体之间表情和动作特征明确区分。
