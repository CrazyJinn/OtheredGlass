# 角色设计图提示词模板（DesignSheet）

> DesignSheet 通过**文生图**方式生成，聚焦角色外貌，不涉及衣着设计。
> 角色统一穿着深色基础衣物（如黑色贴身背心+深色短裤），与肤色形成高对比，衣着由后续 IllusDesign 专门处理。

---

## 提取映射

从图节点和文件中提取细节，按以下维度组织，确保每个维度的细节完整无遗漏：

**数据来源**：
- **AppearanceStyle 节点**：appearance（外貌描述）、color_direction（色彩方向）、shape_language（形状语言）、visual_tone（视觉气质）、first_impression（第一印象）、memory_points（记忆点）
- **`00_init/美术风格.md`**：全局美术风格（画风、头身比、渲染风格、设计图/立绘规格等）

| 数据来源 | 图节点字段 | 提取维度 | 细节粒度示例 |
|---------|----------|---------|------------|
| AppearanceStyle.appearance | 体型 | body | 身高、体型曲线、肩线、站姿 |
| AppearanceStyle.appearance | 面部 | face | 脸型、眼型/眼色、眉型、鼻、唇色/唇形、默认表情 |
| AppearanceStyle.appearance | 发型 | hair | 发色、长度、发型、质感、碎发细节 |
| AppearanceStyle.appearance | 特殊标记 | body marks | 疤痕、纹身、胎记、身体异征 |
| AppearanceStyle.color_direction | 色彩方向 | appearance 配色 | 发色、瞳色、肤色等外貌配色 |
| AppearanceStyle.appearance | 体态气质 | posture | 默认站姿（仅静态，双手自然垂于身侧） |
| 00_init/美术风格.md | 风格 | dynamics | 飘动物品、风的效果 |

## 输出模板

```markdown
# [角色名称] 设计图提示词

## 三视图提示词

[按以下顺序，用自然语言写一段完整的画面描述：]

1. **开头声明**：角色设计图，[从美术风格.md 读取背景色]背景，全身三视图（正面、侧面、背面）
2. **体型**：[身高/体型/曲线/肩线]
3. **面部**：[脸型/眼型+眼色/眉型/鼻/唇/默认表情气质]
4. **发型**：[发色/长度/发型/质感/碎发细节]
5. **贴身基础衣物**：穿着深色基础衣物（如黑色贴身背心+深色短裤），与肤色形成高对比，不涉及服装设计细节
6. **外貌配色**：[发色、瞳色、肤色等外貌相关配色]
7. **特殊标记**：[疤痕/纹身/胎记/身体异征]
8. **风格标签**（放末尾）

## 玩家记忆点（设计重点）
- [从 AppearanceStyle.memory_points 提取，确保这些元素在提示词中被强调]
```

## 编写要点

### 提示词核心规则

1. **自然语言优先**：用完整的描述性语句，而非逗号分隔的关键词
   - 推荐：`身形修长，肩线略窄，四肢纤细，腰线清晰`
   - 避免：`修长, 窄肩, 纤细, 收腰`
2. **主体 + 细节 + 风格**：先写清楚主体，再补充细节和风格
3. **明确用途**：开头声明"角色设计图"让模型理解生成目标
4. **配色写成描述**：不要只写"黑色长发"，写成"及腰的黑色直发，发尾微微卷曲，在光线下泛着深蓝色光泽"
5. **风格词放末尾**：美术风格和参考作品放在提示词最后

### 三视图专用规则

1. **三视图格式**：单张图片包含正面、侧面、背面三个视角并排展示
2. **一份提示词**：每个角色仅一份提示词
3. **背景色**：从美术风格.md 读取角色图片背景色，提示词中包含"[背景色]背景"
4. **全身像**：每个视角完整展示角色全身设计
5. **三视角一致**：同一角色三个视角保持外观一致
6. **不使用负面提示词**：Seedream 通过正面描述控制画面
7. **静态姿态**：设计图仅展示静态站姿，双手自然垂于身侧或微微张开，禁止出现交叠、叉腰、持物等动态手部动作。角色的体态气质差异通过肩线、重心、含胸/挺胸等躯干状态体现，手部动作留给立绘和精灵帧表现

### 提取原则

1. **只提取不创作**：所有视觉细节从图节点字段（AppearanceStyle）和 `00_init/美术风格.md` 提取，不添加数据中未提及的元素
2. **不遗漏**：对照提取映射表逐项检查，确保每个维度都有覆盖
3. **细节转自然语言**：美术设定中的列举式描述转为连贯的自然语言句子
