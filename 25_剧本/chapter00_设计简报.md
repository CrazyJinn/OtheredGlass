# 序章 设计简报

> 本章是整部作品的**现实起点与机制锚点**：以陆择现代生活的最后一晨起笔，经骤然死亡，落到伊芙宣告试炼使命，为 chapter 01（灵魂穿越至陈默）做直接衔接。纯线性叙事，无玩家选择点。

## 设计支柱

1. **让玩家体会陆择对现实生活的疏离与疲惫**——酒店醒来后只想逃离的局促感，是对「活着但不在场」状态的呈现。
2. **让玩家感受死亡的骤然与不可控**——车祸不预告、不可逆，把「日常」与「死亡」并置产生震撼。
3. **让玩家理解试炼机制的重量**——拯救弱者的使命 + 只能在关键选择处干预的限制，为全篇互动叙事建立规则地基。
4. **建立伊芙作为引路人的可信与神秘**——她掌握规则但只揭示必要信息，玩家需对她既信赖又存疑。

## 情感弧线

```
宿醉清晨的尴尬疏离（冷蓝·酒店）
        │ 逃离成功 → 短暂轻松
        ▼
车祸的骤然与不可抗（冷灰·马路）  ← 情绪坠落点
        │ 死亡 → 迷茫真空
        ▼
灵魂夹缝的光明与悬念（暖白·夹缝空间）
        │ 伊芙告知使命
        ▼
使命沉重 + 重获意义的微光（复杂张力）  ← 终点
```

关键转折：马路-路口是情绪坠落点（生→死）；灵魂夹缝是情绪反转点（死→新生使命）。下游 outliner 排 scene 节奏须让两处转折有足够呼吸。

## 戏剧意图

- **建立**：陆择的现实生活状态（疏离、一夜情、逃避联结）；灵魂穿越试炼机制（六个试炼 / 每个 30 天 / 仅在关键选择干预）；伊芙的引路人身份。
- **转折**：从生到死（生理终点）；从无意义日常到被赋予使命（意义重启）。
- **收束**：收束陆择的现代生活线——chapter 01 起他将以灵魂形态介入他人命运，本章是「陆择作为陆择」的最后叙事。

**核心主题问题**：死亡是终结，还是另一种开始的门票？——本章向玩家提出这个问题，伊芙的规则回答了一半，另一半留给后续试炼兑现。

## 本章核心循环

- **即时体验段（0–30 秒）**：读对话感受场景氛围转换（酒店冷蓝 → 马路冷灰 → 夹缝暖白），在 3 次视觉对比中体认陆择状态的剧变。
- **本章节目标（5–30 分钟）**：理解陆择是谁、他遭遇了什么死亡、灵魂试炼机制是什么——为本作世界观与互动机制建立认知地基。
- **长期留存钩子（跨章节）**：六个试炼的悬念（谁能被拯救？失败的代价？）；「只能在关键选择干预」的规则承诺（chapter 01 起玩家选择的重量）；陆择作为灵魂穿越者的身份将如何重塑他对生死的理解。
