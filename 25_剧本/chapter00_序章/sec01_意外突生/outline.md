# sec01 意外突生 · chapter 0

## 方向（direction）
sec01 从咖啡店暖意到雨街死亡的两段滑坡，落点是全章唯一硬翻转——车祸。前段（咖啡店）延续 sec00 海王轻佻、节奏明快，建立「日常暖意」、把「这是个有未来的都市日常」的**期待**泵到最满；后段（路口）一场**无因果的车祸**把陆择猝然抹除，从日常骤降到死亡虚无。**车祸无角色因果——不靠陆择的意志或过失赋予意义；承重的是「日常感搭得多真」+「主角竟在序章就死」的结构性惊愕（期待打破），不是 grief。** 车祸必须猝然、快而硬，两三句内落定。

## 情感弧（emotion_arc）
世俗暖意（咖啡店廉价日常的暖，延续 sec00 海王调性，泵「日常感」期待）→ 日常烦躁（出门遇雨没伞）→ 猝然虚无（无因果车祸硬翻转，全章谷底）。两段 scene 之间是一次暖→冷的色温硬切，节末黑场（1–2 拍）是全章唯一硬翻转的视听锚点，随即被 sec02 明亮夹缝的反差拽成「然后呢？」的好奇。

## 约束（constraints）
- 车祸必须猝然、快而硬——不能用蒙太奇、慢镜头或内心独白软化；死亡在两三句内落定（沿用原 sec01 的硬切写法）。
- 咖啡店段的撩拨延续海王人设，但功能是**泵「这是个有未来的都市日常」的期待**（好让车祸把它撕狠），不是「悼念这份暖意」；暖意写成**廉价日常的暖**（热咖啡 / 陌生脸红 / 小店安全感），**禁止**写成 sec00 那种暧昧博弈的暖。陆择声音支柱（温和讨喜 + 玩世不恭 + 反问玩笑）保持一致。
- 小夏是龙套：用 narrate 描写脸红反应，不 say、不 show 立绘，避免立绘出图成本。
- 车祸**随机、无因果、纯荒诞抹除**——禁止用陆择的意志 / 过失 / 赶飞机的急切赋予意义；他的死没有「他自己的原因」。承重靠「日常感搭得多真」+「主角竟在序章就死」的期待打破，不是 grief。sec00 末「来得及」的回响转为**存在反讽**（他算得清时间，可命运不跟他算），不再作因果伏笔。
- 陆择穿完整商务休闲装（开衫+白衬衫+深灰长裤，sec00 末从顾盈处拿回白衬衫）。
- 节末黑场自然结束，无 jump / ending——publisher 合并后顺序进入 sec02 预分配 scene id「夹缝」。

## 场景段：`咖啡店`
- 场景：`街角咖啡店-点餐台`
- 时段：清晨
- BGM：`晨咖`（play, loop）

### 职责（purpose）
陆择进街角咖啡店买咖啡清醒，延续海王轻佻——随口撩店员小姑娘几句，小姑娘脸红。功能是**把「这是个有未来的都市日常」的期待泵到最满**：越松弛、越世俗、越像理所当然的清晨，下段无因果的车祸把它撕开时反差越冷、越虚无。暖意是**廉价日常的暖**，不是 sec00 那种暧昧博弈的暖，也不为悼念——只为让玩家深信「日常会继续」。小夏为龙套，全程用 narrate 描写脸红反应，不 say、不 show 立绘。

### 节拍（beats）
1. 陆择推开咖啡店的门，清晨小店暖黄灯光、咖啡机蒸汽——与即将到来的雨街冷色形成最后一层暖色铺垫。
2. 点餐台后是扎马尾的年轻女店员小夏；陆择点美式，宿醉未醒、懒懒地。
3. 陆择随口撩两句（早班眼睛亮 / 夸你别紧张），温和讨喜式的轻佻——是海王让人脸红的「会撩」，不是猥琐。
4. 小夏耳根红、递咖啡时手抖碰了一下又缩回——全程 narrate 描写反应，不 say、不 show 立绘。
5. 陆择接过咖啡，笑了笑，转身推门出去——把暖意留在身后，门一开就是雨。

### 母题锚点（motif_anchors）
- 咖啡（陆择要清醒赶飞机的现实盘算，承接 sec00 末「找杯咖啡清醒一下」）。
- 小夏的脸红（海王魅力的最后一笔，与下段死亡的虚无形成「生的温度」反衬）。
- 暖黄灯光（与下段雨街冷光硬切的色温分界）。

### 衔接（transition）
推门出去 → 路口雨天硬切：暖黄灯光瞬间被雨幕冷光替换，情绪从轻佻暖意骤降到湿冷烦躁。

## 场景段：`路口`
- 场景：`马路-路口`
- 时段：阴天白天
- BGM：`雨路`（play, loop）

### 职责（purpose）
全章唯一情绪硬翻转（turning point）——车祸必须快而硬、且**无因果**。从「出门遇雨没伞」的日常烦躁，直接落到一场猝然的、没有理由的抹除。**车祸不是陆择主动行为的代价，也不呼应赶飞机**——就是荒诞地、随机地发生；承重的是「日常突然被撕碎」的期待打破 + 荒诞虚无，不是「他的过失」的扎人。

### 节拍（beats）
1. 门一推开雨泼下来，陆择没带伞，缩在门檐下举咖啡杯挡雨。
2. 自言自语抱怨「真讨厌下雨天」（说出口的日常烦躁）。
3. 雨中行进（去机场巴士的路上，普通穿街口），日常、不急、无起意——他有两小时，从容。
4. 雨幕里冲出来的一样东西——撞击声。然后什么都没有了（车祸两三句内落定，快而硬、**无因果**，禁止蒙太奇 / 慢镜头 / 内心独白软化；陆择甚至没来得及反应）。
5. 画面黑场（雨声白噪 1–2 拍），作为硬翻转的视听锚点——随即被 sec02 明亮夹缝打破。

### 母题锚点（motif_anchors）
- 雨（洗刷 / 净化的过渡意象，承接灵魂夹缝的「明亮通透」）。
- 机场巴士的灯光（他正要去的方向、日常未来的一个普通落点——下一秒被无因果抹除，反讽最冷）。
- 撞击 + 黑场（全章唯一硬翻转的视听锚点）。

### 衔接（transition）
黑场 → sec02「灵魂夹缝」明亮通透空间：灵魂从躯体剥离，画面从雨夜黑场转入明亮治愈的夹缝，陆择着装同步从商务休闲蜕变为云雾蔽体，完成世俗身份剥离隐喻弧的最后一跳。
