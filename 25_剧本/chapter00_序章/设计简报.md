# 序章 · 设计简报

> 本章结构段锚点。下游 `chapter-outliner` / `chapter-dialoguer` 以此对齐创作意图。
> 统合 Scene（线性，无分支）：sec00 酒店-客房 → sec01 街角咖啡店-点餐台 → sec01 马路-路口 → sec02 灵魂夹缝-夹缝空间。

## 设计支柱

1. **让玩家在 30 秒内对陆择形成鲜明人设印象**——玩世不恭、轻车熟路的都市海王，把一夜情当稀松平常事，与同样游戏人间的顾盈心照不宣地体面收场。酒店客房段必须把这种"各取所需、互不留恋"的松弛写到玩家能嗅出暧昧过后的轻佻与洒脱。
2. **让死亡猝不及防**——马路-路口的车祸必须打破玩家对"都市日常开场"的预期。从轻尴尬的清晨直接跌入确定的死亡，是本章不可妥协的情感冲击点。
3. **让玩家清晰理解试炼机制**——六个试炼、每个 30 天、灵魂穿越拯救弱者、只能在关键选择处干预。这是整部作品玩法的根基，灵魂夹缝段必须揭示得干净、无歧义。
4. **让玩家对伊芙产生好奇与微妙不信任**——以天使引路人身份登场，但她的动机、立场、信息来源必须留白。她不是工具人 NPC，是长期关系对象。

## 情感弧线

**起点（轻佻松弛 / 玩世不恭）**：酒店客房，清晨宿醉，两个海王一夜情后的心照不宣与体面收场——陆择与顾盈谁都不当回事、谁都不留恋，调情式洒脱告别。情绪温度暧昧轻快、节奏明快。

↓（逃离酒店，转入雨天马路）

**中段转折（猝然惊愕 / 谷底）**：车祸。情绪从轻佻玩世不恭骤降到死亡的虚无断点。这是本章唯一一个情绪硬翻转——不能用蒙太奇软化，要让玩家"啊？"一下。

↑（灵魂剥离，进入灵魂夹缝）

**终点（明亮中的茫然 + 被赋予使命的微妙重量）**：灵魂夹缝的治愈通透感与陆择的茫然并存；伊芙告知试炼规则后，情绪升到一个新的"死后"稳态——不是悲伤，是被塞进一个比活着更大的命题里的轻微失重。

**关键转折点**：车祸（生→死）。下游 outliner 排 scene 节奏时，前段（酒店）需轻佻明快、后段（夹缝）需稳、转折（车祸）必须快而硬。

## 戏剧意图

- **建立**：陆择的人设（玩世不恭、沉溺浅层关系的都市海王）；世界观（现代现实 → 死后灵魂夹缝 → 试炼穿越的机制设定）；伊芙的引路人身份；"拯救弱者"母题。
- **转折**：主角弧的物理断点（现代生活不可挽回地结束）；玩家认知的转折（以为是都市日常叙事，结果是灵魂试炼叙事）。
- **收束**：陆择现代生活的彻底收束——这一晨之后再无"原版陆择"。

**核心主题问题**：当一个把"用浅层肉体关系回避真实情感"活成本能的海王，在死后被强行塞进"拯救陌生灵魂"的使命，他要如何面对一段真正无法用脱身技巧应付的连接？

> 下游 dialoguer 写对话时回看此问题保持主题一致：陆择的每一句都应折射他对真实连接的回避——表面轻佻游刃有余，实则从不投入。

## 核心循环

- **即时体验段（一句对话 / 一个氛围切换，0–30 秒）**：读对话感受人物；在 scene 切换处接收氛围冲击（酒店轻佻 → 车祸冷雨冲击 → 夹缝明亮治愈）；看到伊芙现身的立绘变化。
- **本章节目标（5–15 分钟）**：看完序章线性剧情，理解主角是谁、他怎么死的、游戏要他做什么。
- **长期留存钩子（跨章节）**：六个试炼各自是什么、要拯救谁（每章一个？）；伊芙的真实身份与动机；"只能在关键选择处干预"的规则如何在玩法中落地；为 chapter 01（陈默跳江 / 灵魂穿越）的直接衔接埋下预期。

## 分节规划

序章按情感弧的三个段落感切成 **3 节**（sec01 含 2 个 Scene，其余各 1 个）。

| section_no | title | 所含 Scene + scene-block id | 戏剧职责（全章情感弧位置） |
|------------|-------|------------------------------|---------------------------|
| 0 | 酒店醒来 | 酒店-客房（id `酒店`） | 起点：轻佻松弛 / 玩世不恭——建立陆择「都市海王」人设 |
| 1 | 意外突生 | 街角咖啡店-点餐台（id `咖啡店`）+ 马路-路口（id `路口`） | 硬翻转：车祸猝然、快而硬，陆择之死（全章唯一 turning point） |
| 2 | 灵魂夹缝 | 灵魂夹缝-夹缝空间（id `夹缝`） | 终点：明亮中的茫然 + 伊芙揭示试炼规则，jump file 衔接 chapter01 |

> sec01 的「街角咖啡店-点餐台」（id `咖啡店`）为**提纲段由 outliner 增设**（结构段原规划每节 1 Scene），用以泵「日常感」期待、承重车祸的期待打破；scene-block id 章内唯一。

> 各节 scene-block id 沿用上表预分配值（章内唯一）；下游 outliner/dialoguer 按节产出 `chapter00_sec0{0,1,2}_*`；发布时 `chapter-publisher` 按 section_no 合并 3 节为单一章 JSON。

### sec0 酒店段 · 挑逗互动锚点

> 供下游 dialoguer 展开 sec0 对话时取用。海王 × 海王的清晨，基调是「轻车熟路的暧昧 + 互不留恋的洒脱」——挑逗服务于立人设与为车祸蓄势，不是色情。尺度卡在 R15 暧昧留白：前一夜的性是既成往事，本场不回闪、不写实质性行为。

可用互动母题（择 2–3 个展开，勿堆满）：

- **赖床肢体语言**：清晨未起，指尖、发丝、贴耳低语等小动作；谁先起身谁掌节奏，另一方懒洋洋反撩。
- **调侃式双关**：互评对方「昨晚」「身手」「够不够专业」，玩笑话包装试探与自夸——海王对话是博弈，不是示弱。
- **穿衣/整理的视线交错**：一方裸身或半裸走动找衣物，另一方不避视线反而点评；视线即调情。
- **联系方式的反转**：不走「示好加微信被推开」的旧套路。两人都心知肚明「不留更洒脱」，或留了也明说「不会打」，把海王式不粘人写到明面。
- **临别一撩**：门口的收尾动作（吻、轻咬耳垂、一句暧昧约定或干脆不约定），把洒脱推到顶——随即车祸硬切，让玩家刚尝到轻佻的甜头就被死亡砸懵，反差最大化。

**尺度红线**：本场不出实质性行为描写；挑逗服务于「建立陆择海王人设 + 车祸前情绪蓄势」，不喧宾夺主。顾盈全程与陆择势均力敌，是被撩也能反撩的对手，不是被推开的示好方。

---

> 创作约束回显：本章**无玩家选择点（Choice）**——车祸与伊芙告知规则都是确定性事件。分支玩法从 chapter 01 开始。下游 outliner 据此定拓扑：纯线性骨架，无分支节点。
