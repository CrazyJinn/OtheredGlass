# sec02 灵魂夹缝 · chapter 0

## 方向（direction）
灵魂夹缝——伊芙以引路人身份揭示试炼规则（六个/30天/灵魂穿越拯救弱者/仅关键选择可干预），为 chapter01 直接衔接。伊芙动机留白，玩家应生好奇与微妙不信任。陆择不退化为被动听众——以海王式轻佻反弹贯穿人设（反衬伊芙平静），于「拯救弱者」处被击穿、重量走 narrate 内化（不直给 grief，维持全章冷基调）。

## 情感弧（emotion_arc）
明亮中的茫然 + 被赋予使命的微妙重量（全章情感弧终点稳态）。

## 约束（constraints）
- 试炼规则揭示必须干净、无歧义：六个试炼、每个30天、灵魂穿越拯救弱者、只能在关键选择处干预。
- 伊芙的动机、立场、信息来源必须留白——她是长期关系对象，不是工具人 NPC。
- 伊芙（月白薄纱天使裙、穿衣、神圣有序）与陆择云雾蔽体（褪尽世俗、赤足）的「她穿衣 / 他云蔽」对比须自然呈现。
- 结尾用 jump file `chapter01_新皮肤` 直接衔接 chapter 01，不使用 ending。
- 陆择人设贯穿到死后——被告知死讯/规则时先用海王式轻佻反弹（解构/反问/不接茬），不温顺接受；反弹同时反衬伊芙的平静权威。
- 「拯救弱者」是本节穿透点——此句击穿陆择的轻佻防御；击穿后重量走 narrate 内化（轻佻失效、话到嘴边没了/防御性微笑僵住），禁止外化为直给的接受宣言或 grief。
- 伊芙留白走非语言破绽——在某个揭示词上漏出一丝读不透的不自然（目光/语气停顿），让玩家意识到「她知道的远比她说的多」；禁止写成语言层刻意拒答（「这个不重要」式 NPC 拒答）。
- sec02 故意悬置陆择的当下私人赌注——他刚死、茫然、未投入，「拯救谁/失败代价」推迟到 chapter01+ 长弧显影；失重感来自「使命大于他、他还来不及在乎」。禁止 dialoguer 给陆择加当下的使命感/投入/拯救决心（破坏反 grief 与推迟同情的基调）。

### 职责（purpose）
揭示试炼机制（整部作品玩法的根基）+ 引出伊芙作为长期关系对象；为 chapter 01（陈默跳江/灵魂穿越）做直接衔接。终点情绪：明亮中的茫然 + 被赋予使命的微妙重量。

### 节拍（beats）
1. 陆择的灵魂在夹缝空间苏醒——着装已彻底脱离世俗，变为云雾蔽体（流动的白云环绕身体、自然遮挡重点部位，赤足）。
2. 伊芙以天使灵魂引路人身份现身（月白薄纱天使裙、穿衣、神圣有序），与陆择的云雾蔽体形成「她穿衣 / 他云蔽」的对比——一个仍属秩序之内，一个已褪尽世俗。
3. 伊芙平静告知陆择已死；陆择不温顺接受，而以海王式轻佻反弹（解构/反问/不接茬）——人设从 sec00/sec01 贯穿到死后；伊芙不吃他任何调情套路，平静不被带走。
4. 伊芙主动、平铺直叙揭示试炼规则（六个/每个30天/灵魂穿越拯救弱者/仅关键选择干预，干净无歧义）；其中**「拯救弱者」击穿陆择的轻佻防御**——他第一次说不出抖机灵的话，重量压进 narrate（防御性微笑僵住/话到嘴边没了），失重地接住使命。禁止外化为接受宣言或 grief。
5. 伊芙的留白以非语言破绽呈现：在某个揭示词上漏出一丝读不透的不自然（目光/语气停顿），让玩家意识到「她知道的远比她说的多」——她不是工具人 NPC，而是带自身故事的长期关系对象；玩家应生好奇与微妙不信任。
6. 伊芙宣告第一个试炼即将开始，画面淡出，jump `chapter01_新皮肤`；陆择不再抖机灵——全章第一次**安静地被送走**，「轻佻失效」状态延续到淡出，与 sec00 聒噪海王形成全书级反差（结尾余响，不新增戏剧点）。
