# sec02 灵魂夹缝 · chapter 0

## 方向（direction）
灵魂夹缝——伊芙以引路人/宣判者身份揭示陆择的判决与赎罪机会：陆择生前海王情债，按罪本该下地狱；伊芙以其「懂感情」的海王本事为由给他一条赎罪路——六个试炼、每个 30 天、灵魂穿越拯救一个在感情中受挫的人、仅关键选择可干预，做成则罪账勾销。获选机制（「为什么是你」）**明确回答**——罪赎同源，他欠的是情债，能还的也是情。伊芙**自身**的动机/立场仍留白（走非语言破绽）。陆择不退化为被动听众——以海王式轻佻反弹贯穿人设（反衬伊芙平静），连「本该下地狱」的判决也以轻佻悬置（赌注在场、他装作不在乎）；于「拯救感情受挫者」处被击穿、重量走 narrate 内化（不直给 grief，维持全章冷基调）。

## 情感弧（emotion_arc）
明亮中的茫然 + 被判下地狱又获赎罪机会的微妙重量（全章情感弧终点稳态）。茫然 → 判决落下时的轻佻反弹（赌注未沉）→「赎罪=救感情受挫者」击穿轻佻 → 安静被送走。

## 约束（constraints）
- 判决与赎罪前提必须由伊芙台词干净、无歧义地揭示：陆择因生前海王情债本该下地狱 → 因懂感情获赎罪机会 → 六个试炼、每个 30 天、灵魂穿越拯救感情受挫者、仅关键选择可干预 → 做成则消除罪恶获得救赎。
- 获选机制（「为什么是你」）**明确回答**（罪赎对位：欠的是情债，能还的也是情），不留白；伊芙**自身**的动机、立场、信息来源仍留白——她是长期关系对象，不是工具人 NPC。
- 伊芙（月白薄纱天使裙、穿衣、神圣有序）与陆择云雾蔽体（褪尽世俗、赤足）的「她穿衣 / 他云蔽」对比须自然呈现（场景视觉不动）。
- 结尾用 jump file `chapter01_新皮肤` 直接衔接 chapter 01，不使用 ending。
- 陆择人设贯穿到死后——被告知死讯/判决/规则时先用海王式轻佻反弹（解构/反问/不接茬），不温顺接受，也不外化恐惧/痛悔；反弹同时反衬伊芙的平静权威。
- **赌注在场但人物悬置**（关键，替代旧「悬置私人赌注」约束）：「下地狱」判决制造客观强赌注，但陆择以海王式轻佻悬置处理——他还没来得及怕、装作不在乎，赌注悬顶而人物主观不投入。禁止把陆择写成恐惧/痛悔/拯救决心（破坏反 grief 与推迟同情的基调）；失重感来自「判决大于他、他还来不及在乎」。
- 「拯救感情受挫者」是本节穿透点——此句击穿陆择的轻佻防御（他的海王之罪与试炼对象形成镜像）；击穿后重量走 narrate 内化（轻佻失效、话到嘴边没了/防御性微笑僵住），禁止外化为直给的接受宣言或 grief。
- 伊芙自身留白走非语言破绽——在某个揭示词（尤以说「为什么是你」的罪赎对位时）漏出一丝读不透的不自然（目光/语气停顿），让玩家意识到「她知道的远比她说的多」；禁止写成语言层刻意拒答（「这个不重要」式 NPC 拒答）。

### 职责（purpose）
揭示试炼机制与赎罪前提（整部作品玩法的根基 + 主角命运的对位结构）+ 引出伊芙作为长期关系对象；为 chapter 01（陈默跳江/灵魂穿越——陈默正因感情受挫而跳江）做直接衔接。终点情绪：明亮中的茫然 + 被判下地狱又获赎罪机会的微妙重量。

### 节拍（beats）
1. 陆择的灵魂在夹缝空间苏醒——着装已彻底脱离世俗，变为云雾蔽体（流动的白云环绕身体、自然遮挡重点部位，赤足）。
2. 伊芙以天使灵魂引路人身份现身（月白薄纱天使裙、穿衣、神圣有序），与陆择的云雾蔽体形成「她穿衣 / 他云蔽」的对比——一个仍属秩序之内，一个已褪尽世俗。
3. 伊芙平静告知陆择已死；陆择不温顺接受，而以海王式轻佻反弹（解构/反问/不接茬）——人设从 sec00/sec01 贯穿到死后；伊芙不吃他任何调情套路，平静不被带走。
4. 伊芙宣判——按陆择生前的罪（玩弄感情、一身情债），他本该去的地方是地狱；陆择仍以海王式轻佻反弹（解构/不接茬，不外化恐惧），赌注在场但他装作不在乎，伊芙平静不被带走。
5. 伊芙递出赎罪机会（罪赎对位：陆择「懂感情」的海王本事用错了地方，恰是能救人的本事）+ 揭示规则——六个试炼、每个三十天、灵魂穿越拯救一个**在感情里走投无路的人**、仅关键选择可干预，做成则罪账一笔勾销。
6. **「拯救感情受挫者」击穿陆择的轻佻防御**——他的海王之罪与试炼对象形成镜像，第一次说不出抖机灵的话，重量压进 narrate（防御性微笑僵住/话到嘴边没了），失重地接住。禁止外化为接受宣言或 grief。
7. 陆择第一次主动追问「为什么是我」（从轻佻反弹转为认真，呼应击穿）；伊芙**明确回答获选机制**（罪赎对位，不再留白），但在作答时走非语言破绽——漏出一丝读不透的不自然（目光/语气停顿），让玩家意识到「她知道的远比她说的多」（留白转移到伊芙自身动机，而非获选机制）。
8. 伊芙宣告第一个试炼即将开始，画面淡出，jump `chapter01_新皮肤`；陆择不再抖机灵——全章第一次**安静地被送走**，「轻佻失效」状态延续到淡出，与 sec00 聒噪海王形成全书级反差（结尾余响，不新增戏剧点）。
