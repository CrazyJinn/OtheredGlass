## 时间说明

## 提取范围

### 开场
陆择酒店醒来 → 车祸死亡 → 伊芙告知试炼规则

### Day 0-10（新皮肤）
陈默跳江 → 灵魂穿越 → 发现转账记录 → 整理身体 → 重返代练 → 偶遇苏晓禾 → 做直播 → 收到沈暮雪私信 → 试训 → 邀请加入二队

### Day 11-20（感情升温）
三条感情线并行发展：
- **苏晓禾线**：跑步避雨 → 超市买菜 → 爬山 → 地铁靠肩 → 生病送吃 → 偷偷看工作
- **林梦线**：房管对喷 → 漫展 → 送回家发现富家千金身份
- **沈暮雪线**：西餐厅 → 路边摊

### Day 22（三选一）
三个未接来电，选择一个女主进行后续剧情

### 后日谈
三条路线各自的结局（苏晓禾/林梦/沈暮雪）

## 注意事项

- evt_005（分支A）和 evt_006（分支B）为互斥分支
- evt_028/029/030 为三条路线各自的结局，互斥
- 角色编号按大纲优先级排列：P0（char_001-char_007）→ P1（char_008-char_009）
- 信息知识层分布：表层(1) = 3 条、参与层(2) = 8 条、深层(3) = 1 条
- link 边中含 1 条因果边（info_009 → info_010：富裕家庭父母缺席导致童年孤独）
