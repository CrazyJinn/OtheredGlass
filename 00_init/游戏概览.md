## 游戏简介

玩家扮演灵魂穿越者**陆择**。他无法直接操控宿主的身体，只能在关键选择节点进行干预——而这些「关键选择节点」，正是玩家手中的选项。

借助神秘的「系统」，陆择能读取宿主近 **10 天**内的信息；更久远的过往，则需要通过环境叙事去拼凑。

**核心循环**：灵魂挤入宿主 → 通过对话与事件了解其处境 → 在关键选择点做出干预 → 选择导向不同分支与结局 → 进入下一个试炼。

> 完整角色名册、事件时间线见 [大纲.md](大纲.md)；「选择分叉」如何建模见 [剧情.md](Schema/剧情.md) 的 Choice 节点。

## 操作说明

Galgame 标准键鼠操作（具体绑定可在设置中调整，见 [设置](#设置)）：

| 操作 | 键鼠 | 说明 |
|------|------|------|
| 推进对话 | 鼠标左键 / 空格 / 回车 | 逐句推进；文字未播完时点击可立即显示全句 |
| 呼出菜单 | 鼠标右键 / ESC | 打开系统菜单（存档 / 读档 / 设置 / 返回标题） |
| 快进（已读） | Ctrl（按住） | 加速跳过已读文本 |
| 自动播放 | A | 切换自动推进 |
| 跳过 | S | 切换全速跳过 |
| 对话历史 | H / 滚轮上 | 查看历史对话记录 |
| 快速存档 | F5 | 写入快速存档槽 |
| 快速读档 | F9 | 读取快速存档槽 |

> 对话框内的功能按钮（Auto / Skip / Log / Menu）布局见 [对话系统](#对话框)。

## 对话系统

### 两种布局模式

#### 模式一：对话布局（角色分列两边）

用于角色之间的对话场景。

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│    ┌──────────┐                    ┌──────────┐    │
│    │          │                    │          │    │
│    │  角色A   │                    │  角色B   │    │
│    │  (PNG)   │                    │  (PNG)   │    │
│    │          │                    │          │    │
│    │ 400×800  │                    │ 400×800  │    │
│    │          │                    │          │    │
│    └──────────┘                    └──────────┘    │
│                                                     │
├─────────────────────────────────────────────────────┤
│  ┌───────────────────────────────────────────────┐ │
│  │  [头像]  角色名称                              │ │
│  │                                               │ │
│  │  对话文本内容...                              │ │
│  │                              [点击继续 ▼]     │ │
│  └───────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────┘
```

#### 模式二：独白布局（角色居中）

用于角色内心独白场景。

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│                    ┌──────────┐                    │
│                    │          │                    │
│                    │  角色    │                    │
│                    │  (PNG)   │                    │
│                    │          │                    │
│                    │ 400×800  │                    │
│                    │          │                    │
│                    └──────────┘                    │
│                                                     │
├─────────────────────────────────────────────────────┤
│  ┌───────────────────────────────────────────────┐ │
│  │  [头像]  角色名称（或省略）                     │ │
│  │                                               │ │
│  │  内心独白内容...                              │ │
│  │                              [点击继续 ▼]     │ │
│  └───────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────┘
```

### 对话框

底部对话框在两种布局下结构统一：

- **头像**：发言角色头像（左上角）
- **角色名称**：头像右侧；独白时可省略
- **正文**：对话 / 独白文本，逐字（打字机）显示
- **继续指示**：正文播完后右下角出现「点击继续 ▼」
- **功能按钮**：对话框边缘的 Auto / Skip / Log / Menu 控件

> 对话立绘规格：**400 × 800 PNG，纯绿背景**（chroma key `#00FF00`）用于合成抠像；场景图须「无角色」，与立绘背景互斥。详见 [美术风格.md](美术风格.md)。

### 文字与演出

| 项 | 说明 |
|----|------|
| 文字显示 | 逐字打字机效果；点击可跳过动画、立即显示全句 |
| 立绘切换 | 按发言角色显示 / 隐藏；支持表情与动作变体（StandingIllustration） |
| 站位 | 对话模式角色分列左右；独白模式居中 |
| 入离场 | 立绘入场 / 离场过渡（具体形式待定） |

## 结局与分支

- **选择分叉**：故事在关键节点呈现玩家选择，不同选项导向不同后续事件。建模见 [剧情.md](Schema/剧情.md) 的 Choice 节点：`Event -[presents]-> Choice -[option]-> Event`。
- **核心抉择**：每个试炼的关键选择（如三女主择一），选项互斥、各通向一条分支线。
- **结局标记**：结局事件以 `BE` / `TE` / `HE` / `NE` 标注（见 [叙事基础.md](Schema/叙事基础.md)）。
