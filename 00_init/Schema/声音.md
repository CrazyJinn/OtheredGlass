# 声音

> 角色如何从文字变成声音——每个角色的基线音色档案（TTS 声音设计参数 + 可复用的 voice_clone_prompt 缓存）。`Character → VoiceProfile` 经 `has_voice_profile` 1:1 关联；基线音色确定后，整章所有台词复用同一 clone prompt。

---

## 定位

- **基线音色，非逐句音色**：每个角色一个 VoiceProfile（1:1）。不同情绪（调侃 / 沉吟 / 愤怒）由 TTS Base 模型对文本韵律的自适应产出，不建情绪多维档案。
- **区别于 LanguageStyle**：`has_voice_style` 指向 LanguageStyle（**文字层**说话方式——词汇 / 节奏 / 口头禅），供 `chapter-dialoguer` 写对白；`has_voice_profile` 指向 VoiceProfile（**声音层**音色档案——instruct / 参考音频 / clone prompt），供 `voice-publisher` 批量配音。两者正交，**边名绝不混用**。
- **产物不进运行时图**：VoiceProfile 的 `ref_audio_path` / `clone_prompt_path` 指向 `15_声音/` 的离线产物；逐句克隆出的 wav/ogg 由 `voice-publisher` 注入运行时 chapter JSON 的 `say.voice` 字段（见 [剧本.md](../剧本.md) 的 voice 字段说明）。

---

## 节点

### 声音档案（VoiceProfile）

每个角色一个。定义角色的基线音色——VoiceDesign 自然语言 instruct + 固化音色的参考音频 + 可复用的 voice_clone_prompt 缓存。基线确定后整章台词复用同一 clone prompt，避免逐句重跑 VoiceDesign（GPU 密集）。

| 字段 | 中文 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| id | 编号 | string | 是 | snowflake Base62 |
| name | 名称 | string | 是 | `<角色名>声音档案` |
| instruct | 声音设计指令 | string | 否 | VoiceDesign 模型的 instruct 文本（年龄 / 性别 / 音色 / 气质 / 语速 / 尾音特征） |
| ref_text | 参考文本 | string | 否 | 固化音色用的参考句（短、贴近角色语气；不直接对外） |
| ref_audio_path | 参考音频 | string | 否 | VoiceDesign 合成的参考音频相对路径 `15_声音/output/<char>_ref.wav` |
| clone_prompt_path | 克隆提示词 | string | 否 | 序列化的 voice_clone_prompt .pt 文件相对路径 `15_声音/output/<char>_clone_prompt.pt` |
| description | 概要 | string | 否 | 简短描述音色气质（1-2 句） |
| status | 流程状态 | int | 否 | `0` |

**status 枚举**：`0` 待设计 → `1` 已完成（instruct 写好 + ref_audio / clone_prompt 固化）。`-1` 级联重置后重做。

> 无审批流程：声音档案由 voice-designer 生成后即 `status=1`，直接参与下游批量克隆。音色好坏是连续主观判断，靠「听一句不满意就改 instruct 重跑」治理，不设二元审批。

## 边

### 声音关联

#### has_voice_profile — 角色拥有声音档案 `1:1`

- **方向**：`Character → VoiceProfile`
- **说明**：角色的基线音色（区别于 `has_voice_style` 指向 LanguageStyle 的「文字说话方式」）

| 属性 | 中文 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| sync | 同步 | boolean | 否 | 默认 `true`（角色属性变更级联重置声音档案为 -1） |

---

## ID 规则

- snowflake Base62，全局唯一，无前缀（同全项目约定）。
- 生成：`python "${CLAUDE_SKILL_DIR}/../../scripts/snowflake_base62.py" -n 1 -q`
- 引用已有角色：按 name 查（`MATCH (c:Character {name:'陆择'}) RETURN c.id`），再 `MERGE (v:VoiceProfile {id:'...'})` + `MERGE (c)-[:has_voice_profile]->(v)`。
