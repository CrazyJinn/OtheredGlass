# 美术风格

## 人物美术风格

### 基础定位
- 风格名称：Japanese Commercial Illustration
- 细分类别：Semi-realistic Anime
- 风格定位：日系商业角色插画
- 用途：角色设定图 / 角色立绘
- 写实度：6.5 / 10，半写实
- 画风倾向：动画风 70% + 写实风 30%
- 头身比：7.5头身
- 风格倾向：轻小说封面风

### 线稿
- 线条粗细：细线稿
- 外轮廓线：略粗
- 内部结构线：较细
- 面部线条：极细
- 线条变化：中等
- 线条风格：圆润柔和
- 线条纹理：光滑干净
- 线条颜色：纯黑

### 上色
- 上色方式：半厚涂
- 主体渲染：Anime Illustration
- 阴影类型：软阴影
- 阴影边缘：柔和渐变
- 明暗对比：低对比
- 光照复杂度：中等
- 光照风格：单主光源
- 环境光：弱
- 高光强度：中等偏弱

### 色彩
- 色调：暖色调
- 色温：偏暖
- 饱和度：中低饱和
- 色彩对比：低对比


### 角色图片背景
所有角色图片（设计图、立绘等）统一使用**纯绿色背景**（chroma key green，#00FF00）。提示词中使用#00FF00色号进行表达。

## 场景美术风格

### 基础定位
- 风格名称：Oil Painting Game Art
- 细分类别：手绘油画质感
- 风格定位：2D 游戏场景背景
- 写实度：7 / 10
- 画风倾向：油画风 100%

### 渲染
- 笔触：厚重笔触，手绘质感
- 纹理：做旧处理
- 氛围基调：黑暗氛围（按场景类型调节）

### 通用风格元素（按场景类型组合，对应 Scene.art_element）
- 粗犷 / 厚重 / 蒸汽朋克 / 做旧处理 / 黑暗氛围
- 参考基调：疯狂的麦克斯（废土题材）

### 提示词硬约束
- 每条场景提示词末尾须含：`油画风格，手绘质感，游戏美术`
- 场景图须含 `无角色`（与角色立绘的 #00FF00 纯色背景互斥，场景不出现角色）
