# 美术风格

## 人物美术风格

### 基础定位
- 风格名称：Korean Flat-shading Illustration
- 细分类别：Korean Cel-shading
- 风格定位：韩系商业角色插画
- 用途：角色设定图 / 角色立绘
- 写实度：6 / 10
- 画风倾向：动画风 60% + 写实风 40%
- 头身比：7.5头身
- 风格倾向：清爽精致的现代商业插画
- 分辨率：1024 * 1024

### 线稿
- 线条粗细：细到中等线稿
- 外轮廓线：略粗
- 内部结构线：较细
- 面部线条：极细
- 线条变化：有（外轮廓到细节的粗细过渡）
- 线条风格：干净利落，略柔和
- 线条纹理：平滑干净
- 线条颜色：深色（深棕 / 近黑）

### 上色
- 上色方式：平涂（Flat-shading）
- 主体渲染：干净色块
- 阴影类型：分层平涂阴影
- 阴影边缘：半硬边（比硬边赛璐璐略柔，带轻微渐变过渡）
- 明暗对比：中等
- 光照复杂度：简单
- 光照风格：单主光源
- 环境光：弱
- 高光强度：简洁点缀
- 皮肤：轻微渐变过渡（非纯平面）

### 色彩
- 色调：清爽高级
- 色温：按角色（中性偏暖）
- 饱和度：中等
- 色彩对比：中等（靠明暗与色块层次）


### 角色图片背景
所有角色图片（设计图、立绘等）统一使用**纯绿色背景**（chroma key green，#00FF00）。提示词中使用#00FF00色号进行表达。

## 场景美术风格

### 基础定位
- 风格名称：Luminous Plein-Air Oil Painting（明亮外光派油画）
- 细分类别：印象派 + 外光派，数字厚涂质感
- 风格定位：2D 游戏场景背景，明亮轻快
- 写实度：6.5 / 10（保留笔触感，不过度写实）
- 画风倾向：油画风 100%
- 视觉锚点：Joaquín Sorolla / Claude Monet / Greg Manchess
- 分辨率：1536 × 1024
- 设计原则：沉重感由剧情承担，场景美术整体保持明亮轻快、阳光通透

### 渲染
- 笔触：松散可见的厚涂笔触（loose impasto），短促轻快
- 纹理：轻微画布肌理，不做旧
- 光照：强阳光、明亮外光，高色温（暖白日光）
- 阴影：彩色阴影（阴影带冷蓝/紫，而非纯黑）
- 空气感：通透、有空气透视（远处偏淡偏蓝）
- 氛围基调：阳光感 / 通透 / 治愈（按场景类型调节）

### 色彩
- 明度：高（画面整体明亮）
- 饱和度：中高
- 色温：偏暖（阳光感），阴影偏冷蓝形成冷暖对比
- 色彩对比：明确但不刺眼

### 通用风格元素（按场景类型组合，对应 Scene.art_element）
- 明亮 / 通透 / 阳光感 / 轻快 / 治愈 / 空气透视
- 参考基调：Joaquín Sorolla 的外光派阳光油画

### 提示词硬约束
- 每条场景提示词末尾须含：`油画风格，明亮外光，手绘厚涂质感，游戏美术`
- 场景图须含 `无角色`（与角色立绘的 #00FF00 纯色背景互斥，场景不出现角色）
