# 美术风格

## 人物美术风格

| 维度 | 取值 |
|------|------|
| **总体风格** | 日系手绘 |
| **线条粗细** | 中等偏细（主轮廓 2–3 px，细节更细） |
| **线条统一性** | 高 |
| **线条风格化** | 半写实 |
| **线条纹理** | 平滑 |
| **线条色彩** | 深灰偏暖（#3A3530） |
| **上色类型** | 赛璐璐（Cel Shading），2–3 层色阶 |
| **阴影硬度** | 软阴影（边缘轻微过渡） |
| **头身比例** | 女性 7 头身 / 男性 7.5 头身 |
| **身体比例** | 半写实（接近真实比例，适度美化） |
| **光影立体** | 中立体（阴影暗示体积，不过度渲染） |
| **主色调** | 中性偏暖（米白/暖灰基底，琥珀橙/暖棕点缀） |
| **饱和度** | 中等 |
| **对比度** | 中等 |


### 角色图片背景
所有角色图片（设计图、立绘等）统一使用**纯绿色背景**（chroma key green，#00FF00）。提示词中使用#00FF00色号进行表达。
